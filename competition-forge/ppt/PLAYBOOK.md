# PPT 编排层 · 从赛道判断到成品 PPT

> **本文件不实现 PPT 生成**，只做编排：决定"这个赛道该讲什么、什么风格、要不要动画"，
> 然后交给 `ppt-master` 执行。
>
> `ppt-master` 位置：`D:\AI\ppt-master\skills\ppt-master\`（v6.7.2，MIT，上游项目，**不复制、不修改**）

---

## 〇、什么时候用本文件

用户要做**答辩 PPT / 路演 PPT / 竞赛 PPT**时：

```
① 先定赛道（competition-forge 第零步）
   ↓
② 读本文件对应赛道的策略
   ↓
③ 加载 ppt-master 技能，按它的路由生成
   ↓
④ 回到本文件做「竞赛专项校验」（页数、数据页、口径一致性）
```

## 一、赛道 → PPT 策略对照

| | 大挑 | 大创 | 小挑/国创赛 |
|---|---|---|---|
| 要不要 PPT | **必需，决胜环节** | 通常不要（校级答辩可能有） | 必需，路演 |
| 定位 | 成果答辩：讲"发现了什么" | 立项答辩：讲"能不能做成" | 商业路演：讲"怎么赚钱" |
| 页数 | **18–22 页** | 12–18 页 | 12–15 页 |
| 时长 | 8–10 分钟讲 + 5 分钟问答 | 5–8 分钟 | 8–10 分钟 |

**大挑是唯一"PPT 不好会直接输"的赛道**，因为它是现场答辩打分。

## 二、大挑 PPT 的骨架（实测 8 份获奖作品归纳）

### 2.1 必有的 6 个结构件

| 结构件 | 位置 | 为什么必须有 |
|---|---|---|
| **封面** | P1 | 实景照片 + 标题 + 副标题 + 负责人/组别/指导老师 |
| **目录** | P2 | 大号数字编号，让评委知道你要讲几件事 |
| **章节页** | 每章前 | 半页图 + 大字章节号，做视觉呼吸 |
| **调研规模页** | 前 1/3 | **决胜页**，8 个可核验数字 + 照片墙 |
| **自创框架图** | 后 1/3 | 你凭什么得奖，就在这一页 |
| **成果页** | 倒数第 2 页 | 论文/专利/采纳证明清单 |

### 2.2 两套可直接用的骨架

#### 骨架 A · 数据型（调研规模是最大卖点）

```
P1   封面
P2   目录（6 条）
P3   章节页：调研背景
P4   政策背景（红头文件截图）
P5   问题提出
P6   章节页：调研设计
P7   调研方法（多种方法并列）
P8   样本与过程（时间轴）
P9   ★ 调研规模数据墙（决胜页）
P10  章节页：调研发现
P11  发现一（数据图）
P12  发现二（数据图）
P13  发现三（数据图）
P14  问题归纳（框架图）
P15  章节页：对策建议
P16  建议一
P17  建议二
P18  ★ 自创模式/框架图（决胜页）
P19  成果清单
P20  结尾（团队 + 致谢）
```

#### 骨架 B · 框架型（有自创理论）

```
P1   封面（副标题直接写框架名）
P2   目录
P3   章节页：研究背景
P4   政策与文献
P5   研究意义（理论/实践/现实）
P6   章节页：研究方法
P7   研究方法（6 种并列）
P8   章节页：现状调研
P9-13  现状（每页一个维度）
P14  章节页：问题分析
P15  问题归纳
P16  章节页：模式设计
P17  ★ 自创框架图（决胜页）
P18  创新点（模式创新 vs 融合创新）
P19  实施路径
P20  结论与展望
```

**怎么选**：调研规模大 → 骨架 A；有自创概念 → 骨架 B；都有 → A 为主，把框架图放 P18。

## 三、四种视觉风格（实测归纳，按主题选）

> **数据先行**：对 24 张获奖 PPT 页面做程序化量化，结果是
> **71% 白底简约、平均饱和度仅 13.8%**。获奖作品看起来"不花哨"。
> 完整量化数据与四套可直接用的配色见 `competitions/datiao/visual-style.md`。

| 风格 | 特征 | 适用主题 | 参考案例 |
|---|---|---|---|
| **田园实景风** | 全屏实景照 + 手写体标题 + 绿色系 | 乡村振兴、农业、生态、地理标志 | 12 鲁山（省金） |
| **商务数据风** | 深蓝/墨绿 + 大量图表 + 数据墙 | 金融、经济、产业分析 | 11 绿色金融（省金） |
| **人文纪实风** | 照片墙 + 暖色调 + 圆角卡片 | 文化、中医药、红色专项 | 31 亳州（省铜）、8 红色 |
| **学术简约风** | 白底 + 单色强调 + 大留白 | 通用，**最安全** | 18 莱西（省金） |


### 3.1 配色方案（可直接用）

```yaml
田园绿（地理标志首选）:
  主色: "#2D5016"    # 深绿
  强调: "#C8A45C"    # 暖金
  背景: "#FFFFFF" / 实景图
  辅助: "#F5E6C8"    # 米黄

商务墨绿:
  主色: "#1B5E20"
  强调: "#4CAF50" / "#FF9800"
  背景: "#FFFFFF"

学术简约:
  主色: "#333333"
  强调: "#C62828"    # 单点红
  背景: "#FFFFFF"

人文暖棕:
  主色: "#6D4C41"
  强调: "#C8A45C"
  背景: "#FAF7F2"
```

**给地理标志主题的建议**：深绿主色 + 暖金强调 + 白底或实景。避开红蓝商务色（用滥了）。

### 3.2 跨风格都成立的设计规律

1. 封面必用**自己拍的实景照片**，不用素材图
2. 目录用**大号数字编号**（01-06 或 一、二、三）
3. **一页一个论点**，不堆砌
4. 配色**不超过 3 个主色**
5. **圆角卡片**是社科类主流容器
6. **数字用超大字号**，配小字说明
7. 页脚统一：案例编号 + 学校 + 页码

## 四、动画能力（硬要求）

**PPT 必须有动画，不能是静态图文堆叠。** 竞赛答辩的动画不是为了炫技，是为了**控制评委的注意力节奏**。

### 4.1 ppt-master 的动画能力

`ppt-master` 支持**元素级进场动画**，通过 `svg_to_pptx.py` 的参数控制：

```bash
# 自动为所有元素加进场动画
python scripts/svg_to_pptx.py input.svg -o output.pptx -a auto

# 指定动画类型
# entrance（进场）/ emphasis（强调）/ motion-path（路径）/ exit（退出）
```

同时支持**页面切换效果**（transition）：

```bash
python scripts/svg_to_pptx.py input.svg -o output.pptx -t <切换类型>
```

### 4.2 竞赛 PPT 的动画纪律

| 位置 | 用什么动画 | 时长 | 为什么 |
|---|---|---|---|
| **封面** | 标题淡入 + 副标题延迟 | 0.5s + 0.3s 延迟 | 让评委先看图再读字 |
| **目录** | 6 条依次飞入 | 每条 0.3s，间隔 0.1s | 建立"我要讲 6 件事"的预期 |
| **章节页** | 章节号放大 + 标题右滑 | 0.6s | 做节奏切换 |
| **数据墙** | **8 个数字依次计数/弹出** | 每个 0.2s | **最重要**，让评委跟着数字走 |
| **图表页** | 柱子/折线从左到右生长 | 0.8s | 引导视线 |
| **框架图** | 分块依次出现 | 每块 0.3s | 讲一层出一层 |
| **结论页** | 整体淡入 | 0.5s | 收尾，不炫技 |

### 4.3 动画的禁忌

- ❌ **不要用旋转、弹跳、闪烁**——竞赛不是产品发布会
- ❌ **不要全篇动画**——重点页有，普通页没有，才有对比
- ❌ **不要动画盖过内容**——评委记的是数据，不是特效
- ❌ **切换效果统一一种**——不要这页淡入那页推入
- ✅ **一页内动画不超过 3 组**——超过就乱了

### 4.4 已验证的坑（来自 ppt-master 实践）

1. **`<p:transition>` 的 `dir` 属性**只接受角向 `lu/ru/ld/rd`，写 `"corner"` 会让 PowerPoint **直接报"无法打开"**，且报错不指向具体页
2. 验证动画别只看 python-pptx 能不能读回，**要用 COM 真开一遍**：
   `Presentations.Open` 能开 = 结构合法；`Slides(i).TimeLine.MainSequence.Count` 能读出数字 = 动画被识别
3. `<p:sld>` 子元素顺序必须是 `cSld → clrMapOvr → transition → timing`

## 五、PPT 里的配图（AI 生图 + 科研绘图）

竞赛 PPT 的图分三类，做法不同：

| 类型 | 用途 | 怎么做 |
|---|---|---|
| **实景照片** | 封面、调研现场、照片墙 | **必须自己拍**，AI 生成的一眼假，评委会质疑真实性 |
| **数据图** | 调研结果、对比、趋势 | `pf chart` 或 `figures/SCIENCE-PLOT.md`（顶刊风格） |
| **示意图** | 架构、流程、框架 | `pf chart --spec` 的 framework 类型 |
| **装饰图/背景** | 章节页底图、纹理 | **AI 生图**（`figures/AI-IMAGERY.md`），本机 SD 免费 |
| **IP 形象** | 项目吉祥物 | AI 生图 + `pf whitebg` 压白底 |

**⚠️ 红线**：**调研现场照片、获奖证书、政策文件截图，绝对不能用 AI 生成或修改**。
这是学术诚信问题，被发现直接淘汰。AI 只能用于装饰性、示意性的图。

## 六、调用 ppt-master 的完整流程

### 6.1 准备

```bash
# ppt-master 位置
SKILL_DIR = D:\AI\ppt-master\skills\ppt-master

# 先跑归属守卫（ppt-master 的硬要求）
python "${SKILL_DIR}/scripts/attribution_guard.py"
# 非零结果 → 立即停止，不要绕过
```

### 6.2 路由选择

读 `${SKILL_DIR}/workflows/routing.md`，选一条路由：

| 场景 | 路由 |
|---|---|
| 从零生成 | Generate PPTX — ordinary Default |
| 要快速出 | Generate PPTX — ordinary explicit Quick |
| 有参考图要还原 | Generate PPTX — Image to PPTX |
| 有现成 PPT 要美化 | Generate PPTX — Beautify |
| 要填公司模板 | Create Template → 再 Generate |
| 改已有 PPT | Edit Native PPTX |

### 6.3 给 ppt-master 的输入（本文件负责准备）

调用前，先把这些想清楚并写成文件：

```markdown
# deck-brief.md
赛道: 大挑
风格: 田园绿（主色 #2D5016 / 强调 #C8A45C）
页数: 20
骨架: A（数据型）
动画: 数据墙逐个弹出、图表生长、章节页放大
核心数字: 532户 / 271天 / 896小时 / 16县区 / 52单位
决胜页: P9 调研规模数据墙、P18 自创框架图
素材: fig/ 下的数据图 + img/ 下的实景照片
```

### 6.4 生成后校验

```bash
# 1. 页数对不对
# 2. 每页文字有没有超框（用 COM 导出 PNG 逐页看）
# 3. 动画能不能播（COM 读 TimeLine.MainSequence.Count）
# 4. 数据口径与文档一致
```

## 七、竞赛 PPT 专项校验清单

生成后逐条打勾：

- [ ] 页数在赛道范围内（大挑 18–22，大创 12–18）
- [ ] P1 封面有：标题 + 副标题 + 负责人 + 组别 + 指导老师
- [ ] P2 有目录，编号清晰
- [ ] **前 1/3 有调研规模数据墙**（大挑必需）
- [ ] **后 1/3 有自创框架图**（大挑加分项）
- [ ] 每页一个论点，无堆砌
- [ ] 配色 ≤3 个主色，且与赛道匹配
- [ ] 数据图风格统一（都走顶刊风或都走 pf chart 默认）
- [ ] 实景照片是**真拍的**，不是 AI 生成
- [ ] 动画：数据墙/图表/章节页有，普通页没有
- [ ] 动画类型统一（不混用旋转/弹跳）
- [ ] 页脚统一
- [ ] 所有数字与申报书/报告口径一致
- [ ] 用 COM 真开过一遍，无"无法打开"
- [ ] 导出 PDF 备份

## 八、常见问题

**Q：大创需要 PPT 吗？**
通常不需要。校级答辩可能有，5–8 分钟，用学术简约风，12–18 页，重点讲技术路线图和进度安排。

**Q：能不能直接套用案例的模板？**
不能。配色可以借鉴，但照片、数据、框架名必须是自己的。案例是用来学**结构逻辑**的。

**Q：AI 生成的背景图会不会被看出来？**
装饰性背景（纹理、抽象图形）看不出来，可以用。但**任何暗示"调研现场"的图必须是真拍的**。

**Q：动画太多会不会扣分？**
会。竞赛答辩时间是固定的，动画拖时间。原则：**关键页有、普通页无**，总计不超过 40 秒。

**Q：ppt-master 生成的是可编辑的吗？**
是。它输出的是原生 DrawingML 形状，不是图片，可以在 PowerPoint 里直接改。
