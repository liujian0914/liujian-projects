# 06 · 参考文献

> 申报书的文献部分只有两个要求：**格式对**、**是真的**。
> 第二条比第一条重要得多——编造的文献一旦被查，整份材料的可信度归零。

---

## 一、先查正文有没有引用

改文献列表之前，必须做这一步：

```bash
pf qa 稿.docx
```

报告里会给：

- 参考文献条目数
- 正文出现过的最大编号
- 有条目未被引用 / 有引用找不到条目

**如果正文里有 `[n]` 标注**，文献列表就不能单独换。只换列表会造成全部编号错位——这是实测踩过的：某文档正文 11 条文献每条都被点名引用，只改列表等于把 11 个引用全指错。

正确做法是连正文一起改：

1. 先重写引用这些编号的段落，把英文文献支撑的句子改写成中文文献支撑的句子；
2. 再整表替换；
3. 最后核对编号一一对应。

**如果没有正文标注**，才能直接换列表。中文申报书的惯例是"少而准"：2–3 篇确有必要的西文 + 若干中文，但正文点名提到的作者必须留对应条目。

## 二、GB/T 7714-2015 著录格式

### 常用类型

| 类型 | 标识 | 格式 |
|---|---|---|
| 专著 | `[M]` | 主要责任者. 题名[M]. 版本. 出版地: 出版者, 出版年: 起止页. |
| 期刊 | `[J]` | 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页. |
| 学位论文 | `[D]` | 主要责任者. 题名[D]. 出版地: 保存者, 年份. |
| 报告 | `[R]` | 主要责任者. 题名[R]. 出版地: 出版者, 年. |
| 标准 | `[S]` | 标准编号 标准名称[S]. 出版地: 出版者, 年. |
| 会议论文 | `[C]` | 析出文献主要责任者. 析出题名[C]//论文集主要责任者. 论文集名. 出版地: 出版者, 年: 起止页. |
| 报纸 | `[N]` | 主要责任者. 题名[N]. 报纸名, 年-月-日(版次). |
| 电子资源 | `[EB/OL]` | 主要责任者. 题名[EB/OL]. (发布日期)[引用日期]. URL. |

### 责任者规则

- 中文：3 人以内全部列出，超过 3 人列前 3 位后加"，等"。
- 西文：**姓全大写 + 名缩写**。`RANGNEKAR D.`、`MAERTENS M, SWINNEN J F M.`
- 机构作者直接写机构名。

### 标点

全部用**半角**标点，`. ` `, ` `: ` `(` `)` `[` `]`，条末不加句号以外的符号。

### 示例

```
[1] 李海玲, 王小军. 地理标志农产品品牌建设的地方实践与制度反思[J]. 农业经济问题, 2023, 44(8): 55-64.
[2] RANGNEKAR D. The socio-economics of geographical indications[R]. Geneva: UNCTAD-ICTSD, 2004.
[3] 中华人民共和国国务院. 地理标志产品保护规定[S]. 北京: 中国标准出版社, 2025.
[4] 国家知识产权局. 2024 年地理标志保护工作情况[EB/OL]. (2025-03-15)[2026-09-20]. https://www.cnipa.gov.cn/...
```

## 三、真实性核验：逐条过

**每一条都要查，不能抽查。** 五项核对：

| 项 | 怎么核 |
|---|---|
| 作者 | 知网/万方/Google Scholar 搜标题，看作者是否一致、顺序是否一致 |
| 题名 | 逐字比对，副标题也不能省 |
| 刊名 | 全称，不用简称（"农业经济问题"不是"农经问题"） |
| 年卷期 | 年份、卷号、期号三个都要有 |
| 页码 | 起止页。查不到页码就不要写**

查不到的怎么办：

1. 换一篇能查到的同主题文献（首选）。
2. 只有摘要没全文的，标 `[J/OL]` 并给 URL 与引用日期。
3. **绝对不要编造卷期页码，也不要编造 DOI。**

> 实测教训：一份材料里 `[J/OL]` 条目因为找不到 URL，最后改回 `[J]`——因为编一个 URL 比缺一个 URL 危险得多。

### 政策文件的处理

政策文件不算学术文献，但申报书里必须有。著录方式：

- 有正式发布的：按 `[S]` 或 `[EB/OL]` 著录，给发布机关、文件名、发布日期。
- 只有文号没有出版信息的：写清"发文机关 + 文件名 + 文号 + 发布日期"。

政策文件里的**时间、名称、文号必须逐个核对**。真实事故：某规划文件的印发时间写成 8 月，实际是 7 月。

## 四、正文标注

两种写法，一篇之内统一：

- 方括号紧跟被引内容：`……存在明显落差[3]。`
- 上标形式：`……存在明显落差^[3]。`（Word 里设为上标）

多处引用：`[3-5]`、`[3,7]`。

**标注位置要在句末标点之前**，这是中文习惯（英文在后）。

---

## 五、常见错误清单

- [ ] 西文作者姓名没有全大写
- [ ] 题名用了书名号（GB/T 7714 不用书名号）
- [ ] 期刊条目缺卷号或缺期号
- [ ] 页码写成"1-10"但实际是"1-10,15"（断续页）
- [ ] `[J/OL]` 没有 URL 或没有引用日期
- [ ] 中英文标点混用（中文文献里用半角句点是对的，但逗号容易写错）
- [ ] 同一条文献在不同章节写法不一致
- [ ] 正文标注 `[11]` 但列表只有 10 条
- [ ] 文献条目按语言分组时，编号没有连续（中文 1-9，英文 10-13，要连续编号）
- [ ] 文献段落居中对齐（模板遗留），应改两端对齐 + 悬挂缩进

悬挂缩进的正确设置：左缩进 0.85cm，首行 −0.85cm。这样第二行起对齐，编号突出在左侧。

## 六、文献与论证的匹配

格式对了、文献真了，还有第三个层次：**这篇文献真的支撑这句话吗？**

- 引用一篇讲"欧盟地理标志保护成本分担"的文献，去支撑"我国农户认知不足"——不匹配。
- 文献年份太旧（2004 年的报告）去支撑"2025 年政策现状"——不匹配。
- 综述里写"学界普遍认为 X"，却只引了一篇——不成立。

自查方法：逐条读"你引它的那句话"和"它的实际结论"，能对上才算。

---

## 七、工具

- **检索**：知网、万方、Google Scholar、CNKI 学术搜索。
- **核验**：Crossref API（`https://api.crossref.org/works?query.bibliographic=题名`）能返回 DOI 与出版信息，适合核实西文条目。
- **管理**：Zotero 导出的 GB/T 7714 样式偶尔有偏差，导出后仍要人工过一遍，尤其是中文文献。
- **批量检查**：本技能的 `pf qa` 只能查编号对应关系，**内容真实性必须人工逐条核**，没有捷径。
