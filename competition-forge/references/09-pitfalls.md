# 09 · 踩坑速查

> 全部是实际踩过的，不是"可能会"。动手前扫一眼，能省半天。

---

## 格式与转换

**1. 后缀 `.docx` 但打不开，报 relationship 错误**
文件是 OLE 复合文档（旧 `.doc` / WPS 存出的）。看文件头：`D0 CF 11 E0 A1 B1 1A E1` 就是。先 `pf convert` 转真 OOXML。

**2. 转换后"看着一样"就直接干了**
不行。必须做 PDF 逐页像素比对，全 0 才算无损。没验证就改，出了版式问题无法判断是转换的锅还是自己的锅。

**3. 把旧 `.doc` 丢给"编辑器 SDK"做结构编辑**
某些通道下结构树所有节点类型都返回 `Paragraph`、大纲接口返回空数组，标题层级完全认不出，新增章节格式必然对不上。只能做轻量文本替换。

**4. 直接用 WPS 而非 Word 转换**
原件多半出自 WPS，用 `KWPS.Application` 保真度高于 `Word.Application`。两个都试，先 WPS。

**5. 转完忘了 `app.Quit()`**
后台残留进程锁文件，下次打开报"文件被占用"。

## 遍历与统计

**6. 用 `doc.paragraphs` 数正文**
中文申报书常把全文塞进一个 1×1 表格，`doc.paragraphs` 近乎为空。必须走 `body.iter(qn("w:p"))`。

**7. 用 `id(el)` 给段落去重**
lxml 的子元素代理是临时对象，回收后地址会被复用。用 `id` 判重会把后面的段落误判成"已见过"而**静默跳过**。实测一份 14,465 字的文档因此只统计到 668 字——不报错，只是数少了，最危险的一类 bug。

**8. 统计字数把表格内容漏掉**
同上。另外填空题的表格里全是正文性质的内容，不能当"附件"排除。

**9. 文本框里的段落打乱顺序**
`w:txbxContent` 内的段落在 XML 里嵌在 drawing 内部，遍历时会插在奇怪的位置。做编号重排前要排除。

## 文本修改

**10. 整段突然变粗**
`set_para_text` 只保留 run0 的格式。run0 若是加粗的「（1）小标题」，整段会被加粗。批量替换后**必须**跑 `audit_bold`。修法是还原"首句加粗 + 其余常规"，不要整段取消加粗。

**11. 替换后出现重复字**
跨 run 的文本（"地" 和 "理标志" 在两个 run 里）用字符串 replace 会失败或错位。要按段落整体取文本、整体换、再写回。

**12. 改完字数没变但内容乱了**
`set_text` 类操作会把超链接、域、书签结构清掉。含超链接的段落（如目录、邮箱）不要用整段替换。

**13. 段末空格导致下划线过长**
封面"标签 + 空格填充 + 下划线"的模板里，值末尾的填充空格会被下划线画出来。加空格要加在**标签 run**（无下划线）末尾，并去掉值末尾空格。

## 图表编号

**14. 按字符串匹配重排编号必漏**
总有"图10"写成"图 0"、"表2"带空格、某张图的题注用的是普通样式。必须先按"短且以 图N/表N 开头"归一化样式，再按文档位置自增。

**15. 长度阈值不能省**
不加"≤45 字"的限制，会把正文里"如表3所示"的句子也当成题注改掉。

**16. 编号重排后插图位置看着不对**
因为插图用 `addprevious` 插到了题注前面，题注被推到了图下方。必须 `addnext` 到题注之后。

**17. 图与表数字打架**
真实事故：图里四个产品的执行分全画成 40，表里是 40.24/62.05/40.27/40.44，按图算结论方向都反了。先立 `data.md` 做唯一源，发现不一致时**问"以哪个为准"，不要自己挑一个改**。

## 目录

**18. 标题取不到，做不出目录**
标题没用样式（Normal + 手动加粗）。手工目录或先套样式。真实案例："5.3 未来融资计划"用了正文样式，整节没进目录。

**19. 目录页码差一页**
算完页码后又改了内容/表格/图宽，分页变了。**页码永远最后算**。

**20. 目录本身导致页码漂移**
目录条目增加会让正文后移。用两遍法：先按最终条目数建目录（页码占位），渲染取页，再回填。行数不变，分页才稳定。

**21. 用 Word 域更新目录**
换软件打开时域不自动更新，页码还是旧的。除非确认对方用同一软件且会手动更新，否则填死页码更稳。

## 表格

**22. 表格行文字只显示中间一条**
症状：某行"基础版"渲染成"版"。根因不是行高设成 exact（`trHeight` 往往是空的），而是**行被跨页拆开**。加 `w:cantSplit`。

**23. 长表跨页没有表头**
给首行加 `w:tblHeader`。不加的话第二页开始读者不知道每列是什么。

**24. 修完表格目录页码全错**
`cantSplit` 会改变分页内容（页数可能不变）。必须重算目录页码。

**25. 给模板表格加了行**
基本情况表、经费预算表、意见栏是钉死的结构，加行/合并单元格会被打回。

---

## 图片

**26. 透明 PNG 插进去变黑块**
Word/WPS 不做 alpha 合成，透明像素按 RGB 渲染（通常是黑的）。插之前 `pf whitebg`。

**27. 换图后版式跑位**
新图尺寸与旧图不一致。必须先 resize 到同尺寸。

**28. 换图后半透明区域变实色**
色彩模式变了（RGBA → RGB）。存图时保持原模式。

**29. 两张竖图分别插，第二张题注掉到下一页**
WPS 对含嵌入图片的段落不遵守 `keepNext`/`keepLines`。合成一张横排图，单图单题注。

**30. 题注怎么设 keepNext 都没用**
同上。三条路都试过无效：手写 `<w:keepLines/>` append 到 pPr（违反元素顺序被忽略）、`paragraph_format.keep_together=True`（顺序对，仍被忽略）、把图与题注合并成一段用 `<w:br/>`（照样被拆）。**唯一可行：让"图+题注"整体装得下**——缩图，或删减上方文字。

**31. 图的配色改完看不出变化**
淡色填充的饱和度只有 ~0.04，只换色相根本看不出来。HSV 换色时必须同时把饱和度抬到 0.14 以上。

**32. 改色把语义色也改了**
绿=合规、红=风险、蓝=授权等级这类承载含义的颜色不能动。只对纯装饰配色的图做分化，并在交付说明里写清哪些没动、为什么。

**33. 缩略图看不出改色效果**
按原尺寸裁局部比，或者 `pf` 输出的对比图用 Read 看一眼。缩略图上差别会被抹掉。

## 排版与字体

**34. matplotlib 中文图细得没法看**
用了可变字体（`*VF.ttf`），只注册到 weight 100。换 `msyh.ttc`（微软雅黑，注册了 400/700）。

**35. 负号显示成方块**
`plt.rcParams["axes.unicode_minus"] = False`。

**36. 中文字符型缩进与磅值缩进混用**
`w:firstLineChars`（字符数）优先级高于 `w:firstLine`（磅值）。手动改 `w:ind` 为 left+hanging 会把整块顶到右侧、第二行消失。**模板用哪种就跟哪种，不要改良。**

**37. 弧形连接线压住方块文字**
窄图里必压。改直角折线或直线。

**38. 热力图 x 轴标签挤成一团**
标签内换行，不是缩小字号。

**39. 环形图百分比合计 101%**
四舍五入的错。用最大余数法凑满 100%。

## 环境

**40. 从 shell 调 PowerShell 被安全策略拦，且 PowerShell 工具没有 stdout**
一律写 Python 脚本跑，结果落文件再读。不要在这一环上反复试。

**41. `os.popen` / `subprocess` 调外部程序拿不到输出**
同上，杀软或策略可能拦管道。改走"写文件再读"。

**42. Windows 保留设备名文件（`nul` 等）读不了也删不掉**
必须用 `\\?\` 长路径前缀。`shutil.copy2` 会报 `WinError 87`。

**43. `send2trash` 删成功却抛 `FileNotFoundError`**
别信返回值，删完查文件系统。要真正清理时，先 `os.path.exists` 核实，再去回收站按时间抽查确认。

**44. 控制台输出中文报 `UnicodeEncodeError`**
开头加 `sys.stdout.reconfigure(encoding="utf-8")`。读文件一律显式 `encoding="utf-8"`。

**45. 同一份文件被两条命令互相覆盖**
`pf tables` 输出 `_修订版.docx`，接着 `pf renumber` 又输出 `_修订版.docx`，后一条读的是原始文件，前一条的修改全丢。要么用 `--out` 指定不同的名字做链式迭代，要么原地改（`--out` 与输入同路径，靠 `bak/` 保护）。

## 流程与协作

**46. 交付后对方一保存就覆盖**
`~$xxx.docx` 锁文件说明他正开着。交付前提醒关掉。

**47. 只交文件不交改动说明**
对方下次改的时候会把你的处理全部推翻。改动说明要写清"改了哪几处、为什么、哪些留空待填"。

**48. 拿"未观察到失败"当"不会失败"**
真实事故：某次改配置没出现报错就认定安全，结果连续崩溃 8 次。**交付前必须做一次真实启动/打开验收**，不能只看脚本返回值。

**49. 把原文档的既有问题当成自己引入的**
原文档本身就有 10 处题注掉页。判断前先把原件也导一份 PDF 同页对比，否则会白折腾一轮。

**50. 编数据、编文献图省事**
一次被查，整份材料归零。缺数据就换论证方式；文献查不到就换一篇。真要用估算值，明确标注"估算口径"。

## 2026-10 补记（大创 GIEP 一役新增 12 条）

**51. 清空 runs 统一格式，把图片段落清空了**
`for r in p.runs: remove` 之后图片一起消失，最后只剩题注。清空前必须判 `p._p.findall('.//a:blip')`。

**52. 题注插到了图上面**
`anchor.addnext(pic)` 之后再 `clone_after(anchor, 题注)`，题注会挤到图前。改成 `pic.addnext(caption)`。

**53. 按固定索引批量改段落，插入后索引全偏移**
先按索引加小标题，再用旧索引改后段，编号串位（出现"2. 1.法学研究"）。二次修改一律用**文本锚点**。

**54. 段落带 numPr 又手写序号，渲染成双编号**
接手稿先清所有 `pPr/w:numPr`，编号统一写成**纯文本**。

**55. `firstLineChars` 残留让标题像居中**
`first_line_indent = Pt(0)` 只写 `w:firstLine="0"`，Word 优先认字符型缩进。必须 `del ind.attrib[qn('w:firstLineChars')]`。

**56. 换图按"上一段是不是题注"匹配，误伤邻居图**
结果出现重复图 + 原图被覆盖。换图只认**这张图自己的题注**，且每个关键字**只命中一次**。

**57. 微信收到的文件是只读的，保存报 PermissionError**
`shutil.copy` 会连权限复制。复制后立刻 `os.chmod(dst, 0o666)`；保存走"临时文件→chmod→os.replace"。

**58. 批量去空格把"学    号 25314080118 专业班级"的分隔也吃了**
只处理"数字↔汉字"相邻空格；标签与值之间用**全角空格 U+3000** 保留视觉间隔。

**59. 封面项目名称放大到 15 磅就折行**
长副标题固定 12 磅单行（模板本身就是 12 磅）。宁可缩字号也别让它折行——折行比字号不一致更难看。

**60. 同一份材料里"两条路径/三种体系"前后打架**
写比较段落前先画一张对照表（表 1），三种体系各占一行，正文按表格顺序叙述，不会漏、"不会多"。

**61. "100+ 份""两个以上产区"这类口语化量词**
统一改成"100 份以上""两个产区"。数字口径不一致是评委最容易抓的硬伤。

**62. 只改列表不改正文引用**
换文献后正文 `[n]` 全部错位。改文献必须"条目 + 正文引用"同一次改完，改完数一遍 `[n]` 的个数。

---

## 一句话总结

这个行业的坑分两类：**静默出错的**（遍历漏数据、替换丢格式、编号错位）和**验证不了的**（"看着一样"、"应该没问题"）。前者靠工具和清单兜住，后者只能靠"渲染出来亲眼看一遍"。
