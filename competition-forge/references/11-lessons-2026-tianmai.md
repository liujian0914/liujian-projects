# 11 · 实战教训：一份 25 页竞赛调研报告的返工清单

> 来源：2026 年「挑战杯」哲社类调研报告《田脉智承》全流程返工（用户 6 轮退回）。
> 这份文件只记**踩过的坑和已验证的做法**，不重复方法论。

## 一、最贵的四个错误

### 1. 用 md 重建覆盖了用户的 docx

用户给的底稿里有封面、目录域、页眉页脚、附录、成员表，**一旦用脚本从 md 重新生成，这些全部丢失**，且成员表会被旧版本覆盖（少一个人就炸）。

**规则**：拿到用户的 docx，**只做增量编辑**——保留封面/目录/页眉/附录，只替换正文段落区间。重建只能用于"自己从零生成"的场景。

### 2. 拿不到字数就动手压缩

Word 的"字数"≈ 汉字数 ×1.27（含标点、数字、英文按词计）。按汉字数判断会低估 25%。

**规则**：先 `ComputeStatistics(0)` 量，再决定删多少；留 100—200 字余量。

### 3. 图表题注与图片脱节

替换图片后题注没跟着改、或题注顺序与图片顺序错位，会出现"图 2 是甘特图却写着分析框架"。

**规则**：交付前做一次**全量配对**：
- 用 python-docx 按 body 顺序抽出"图片段 → 下一个题注段"，编号打印成表；
- 把每张图导出成 png，拼 3×2 联系表（contact sheet），人眼过一遍；
- 题注与图不符时，**改题注比改图快**。

### 4. 同一份文件被 Word 锁住后反复失败

`PermissionError` 反复出现时，锁的往往不是 Word，而是 **SearchProtocolHost（缩略图）** 或 explorer 预览。

**规则**（按顺序试）：
1. `Stop-Process WINWORD`
2. `Stop-Process SearchProtocolHost, prevhost, dllhost`
3. `Stop-Process explorer`（会在几秒后自动重启）
4. 仍失败：写到 `out/vN.docx`，再 `shutil.copy2` 覆盖；再失败就换名交付并告知用户。

## 二、九条硬规则

| # | 规则 | 原因 |
|---|---|---|
| 1 | 题目、页眉、封面、摘要页**四处同步** | 用户最先看这四处，改三漏一即视为"没改" |
| 2 | 成员/作者改动要**全文检索姓名** | 封面表、摘要署名、附录分工三处都可能有 |
| 3 | 正文不写"本章/本节/上文" | 模板腔，评委一眼看出是套壳 |
| 4 | 标题用**判断句**，不用名词短语 | 获奖稿通例："（一）四段过滤之下，知晓与执行层层折损" |
| 5 | 摘要**不加粗** | 整段加粗等于没重点，且显得外行 |
| 6 | 表转图可省字数 | 一张 9 行表的文字量≈ 120 字，转图后归零 |
| 7 | 热力图数值用**深墨绿加粗** | 浅底白字打印必糊 |
| 8 | 漏斗/条形**从 0 起算** | 居中对称的"漏斗"与坐标轴读数矛盾 |
| 9 | 政策文件用"政策文件出处"小节，**不要硬塞脚注** | python-docx 无原生脚注，XML 注入易把 docx 写坏（实测两次"文件已损坏"） |

## 三、图表规范（可直接抄）

- 尺寸：宽 11.5—12.0 cm；手机截图 5.0—6.2 cm 或两图并排
- dpi：300（matplotlib `dpi=300`），表格图 320
- 字号：轴标签 ≥10.5，刻度 ≥9，数据标签 ≥10 并加粗
- 配色：主色 `#2F5D2A`，辅色 `#D8A44B`，浅色 `#B9C4A6`，强调 `#A63D2F`
- 图注：宋体 9pt，居中，格式 `图N　说明`
- 表注：置于表上方，宋体 9pt

## 四、交付前自检脚本（照抄改路径即可）

```python
from docx import Document
import re
d = Document(PATH)
ps = [p.text.strip() for p in d.paragraphs]
txt = "\n".join(ps)

# 1 旧内容
for k in ["旧题目关键词", "旧成员名", "旧样本量如372", "本章", "本节"]:
    assert k not in txt, k

# 2 图表编号连续
figs = [int(re.match(r"^图(\d+)", t).group(1)) for t in ps if re.match(r"^图\d+", t)]
assert figs == list(range(1, len(figs) + 1)), figs

# 3 图片与题注数量
imgs = len(d.inline_shapes)
assert abs(imgs - len(figs)) <= 3, (imgs, len(figs))
```

Word 里再补三项：`Fields.Update()`、`TablesOfContents(1).Update()`、`Repaginate()`，最后 `ComputeStatistics(0)` 报字数。

## 五、写作层面的三条经验

1. **数据先自洽再上图**：11 个产区样本量之和必须等于总样本；百分比×总数要能整除到个位。
2. **每个小节至少一处"证据"**：数字、引语、表或图，四者其一，否则删掉该节。
3. **一次性把话说清，不要让用户来回追问**：交付时主动列"改了什么/没改什么/需要你确认什么"。

## 六、本案可复用的成品

- 三代人能力对比（分组柱）
- 分产区认知—执行落差（哑铃图）
- 技术隐性 × 承接能力（气泡散点，气泡=样本量）
- 知识转化漏斗（左对齐 + 留存率）
- 三重断裂闭合回路（2×3 框 + 六箭头）
- 三端界面组图（2 图并排，图内带小标题）
