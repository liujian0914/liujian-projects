# 05 · 排版细则

> 排版不是审美问题，是**阅读效率**问题。评委翻一份申报书平均 3–5 分钟，排版的作用是让他在这几分钟里不迷路、不漏读、不烦。

---

## 一、页面与正文

| 项 | 常用设置 | 说明 |
|---|---|---|
| 纸张 | A4（21×29.7cm） | 少数模板要 A3 骑马钉，看模板 |
| 页边距 | 上下 2.54cm，左右 3.0–3.17cm | 左右留白给装订线 |
| 正文字号 | 小四（12pt） | 大创申请书常用；政府类公文常用三号仿宋 |
| 正文行距 | 1.5 倍 或 固定值 22pt | 固定值更可控，跨软件不变形 |
| 首行缩进 | 2 字符（**字符型**，不是磅值） | 中文正文必须缩进，这是硬规矩 |
| 对齐 | 两端对齐 | 左对齐会右边参差 |
| 段前段后 | 0 | 用行距控制留白，不要用段间距堆 |

正文宽的算法（插图和表格都依赖它）：

```
正文宽 = 页宽 − 左边距 − 右边距
A4 + 左右 3cm  →  21 − 3 − 3 = 15cm（实际可用约 14.5cm）
```

插图一般收到 **12.2cm**，比正文宽略窄，视觉上不顶格，更稳。

## 二、标题层级

三级足够，再多读者会迷路。

| 层级 | 字号 | 字体 | 段前段后 |
|---|---|---|---|
| 一级 1 | 三号（16pt） | 黑体 | 段前 12pt，段后 6pt |
| 二级 1.1 | 四号（14pt） | 黑体 | 段前 6pt，段后 3pt |
| 三级 1.1.1 | 小四（12pt）加粗 | 宋体加粗 | 段前 3pt |

两条硬要求：

1. **必须用样式，不要手动加粗放大。** 目录靠样式抓取，手动格式的标题不在目录里。真实案例：某文档"5.3 未来融资计划"用了正文样式，整节都没进目录。
2. **标题不要带句号**，也不要写成一句话。

## 三、题注（图注/表注）

| 位置 | 内容 | 格式 |
|---|---|---|
| 图下方 | `图1 四类产品认知与执行对比` | 五号（10.5pt）宋体，居中，段前 3pt |
| 表上方 | `表1 调研样本结构` | 五号宋体，居中，段后 3pt |

规矩：

- 图题在下、表题在上 —— 反了读者会先看到名字再看内容，认知顺序错。
- 编号与题名之间空一格，不加冒号、不加句点。
- 题注要和图**同页**。WPS 不遵守 `keepNext`，唯一可靠办法是让"图+题注"整体装得下：缩图，或删减上方文字。

## 四、表格

### 4.1 三线表

学术申报书的标准表格式样：顶线、表头下线、底线，无竖线。

```
───────────────  顶线 1.5pt
 表头  表头  表头
───────────────  表头下线 0.75pt
 数据  数据  数据
 数据  数据  数据
───────────────  底线 1.5pt
```

Word 里实现：表格样式选"无框线"，然后手动加三条横线。不要用"所有框线"——满屏网格会让表看起来像 Excel 截图。

### 4.2 跨页

必须做两件事：

```python
# ① 行不跨页拆开（否则出现"基础版"渲染成"版"）
trPr.append(OxmlElement("w:cantSplit"))

# ② 长表首行重复
trPr_first.append(OxmlElement("w:tblHeader"))
```

第一条是本技能实测最容易被忽略的：症状是某行只显示中间一条竖排的字，根因不是行高设成 exact（`trHeight` 往往是空的），而是行被跨页拆开了。

### 4.3 内容

- 数字右对齐或小数点对齐，文字左对齐。
- 单位写在表头（`金额（万元）`），不要每格重复。
- 空白用 `—` 表示"无此项"，不要留空（留空会被读成"漏填"）。
- 表格字号比正文小一号（五号），否则宽表挤不下。

## 五、目录

- 单独起页，标题写"目录"，居中，不加序号。
- 用 TOC 域或 TOC 1/2/3 样式段落，层级与正文标题一一对应。
- 条目数必须等于标题数。少了多半是标题没套样式，多了是误把正文当标题。
- 页码用点线连接（制表位右对齐 + 前导符 `.`）。
- **页码来自渲染后的 PDF，不是编辑器域。** 见 `02-docx-surgery.md` 的两遍占位法。

---

## 六、页码与页眉

- 页码放页脚居中，小五号。
- 封面不编页码（首页不同 / 分节）。
- 正文从第 1 页起重新编号：插入分节符（下一页）→ 取消"链接到前一节" → 起始页码设为 1。
- 页眉放项目名或学校名，小五号，加下划线；不要放太长的全名，会换行。

---

## 七、封面

封面是评委看的第一页，也是模板最容易做残的一页。四项检查：

**① 标签与值之间要有空格**

"项目负责人刘吉晔"和"项目负责人　刘吉晔"的差别就是专业度。空格要加在**标签那个 run** 的末尾（那个 run 没有下划线），加在值前面会被下划线画成一条短线。

**② 值末尾不要留填充空格**

否则下划线会延伸到空格末尾，看着像多画了一段。

**③ 长项目名压成一行**

15pt 两行、折行后下划线断开，观感很差。降到 12pt，清首行缩进与左缩进，压成一行。

**④ 不要跟缩进较劲**

模板若用字符型缩进（`w:firstLineChars`），它的优先级高于磅值缩进（`w:firstLine`）。手动改 `w:ind` 为 left+hanging 会把整块顶到右侧、第二行消失。**模板用哪种就跟哪种，不要"改良"。**

---

## 八、中英文混排

- 中文用全角标点，西文用半角。
- 数字与中文之间由 Word 自动处理，不要手动加空格（手动加的在别的软件里会变成两个空格）。
- 英文缩写首次出现给全称：`地理标志（Geographical Indication, GI）`。
- 百分号紧跟数字：`46%`，不要 `46 %`。
- 单位与数字之间留一个半角空格：`12.2 cm`、`300 dpi`（中文行文里也有不加的写法，一篇之内保持一致即可）。

## 九、常见排版病

| 症状 | 根因 | 修法 |
|---|---|---|
| 整篇某段突然变粗 | 批量替换把文字压进加粗的 run0 | 按原样式还原"首句加粗 + 其余常规" |
| 图号跳号（图5 后是图7） | 按字符串匹配重排，漏掉样式异常的题注 | 按文档位置重排（`pf renumber`） |
| 目录页码差一页 | 目录算完页码后又改了内容 | 页码永远最后算 |
| 表格行高忽大忽小 | 单元格里有空段落 | 删空段落，用段前段后控制 |
| 段首缩进不一致 | 混用空格、全角空格、字符缩进 | 统一用段落格式的"首行缩进 2 字符" |
| 中英文混排忽宽忽窄 | 段落对齐方式不同 | 全文统一两端对齐 |
| 图片显示模糊 | 原始分辨率低于显示尺寸 | 300dpi 重出图 |

## 十、验收方式

不要靠"看着还行"。三个客观检查：

1. `pf qa` 报告：编号连续、无整段加粗、无重复标点、图宽中位数。
2. 导出 PDF 后**逐页看**，重点看图有没有被裁、题注有没有掉页。
3. 把 PDF 缩到 50% 看整篇：图片大小是否一致、留白是否均匀、有没有哪一页特别挤或特别空。
