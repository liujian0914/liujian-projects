## 2. 先把"批注"翻译成需求，再动手

老师给的是**语音转写**（"本项目以吧…呈呈现的是另一种…"），不能直接当指令，要先抽成条目：

1. 简介要"概括"不要"具象"——**先有一句"本项目是什么"的落脚句**，细节留给后文。
2. 三个排比句必须指向**同一种情形**，否则读者分不清是几件事。
3. 主语不能缺——"询问农户…"要写成"就某规定询问农户，多数受访者无法准确复述"。
4. 定性词换可核查表述——"没有记录"→"无法保证测量的真实性，因此不能成为执行的标准"。
5. 两条路径 vs 三种体系要说圆——**国外两条（欧洲专门保护、美国商标法）+ 我国三套并行 = 三方比较**，不能前面说两条、后面冒出三种。
6. 创新点(2) 要写出组合的名字（本例定为"双镜法"）。
7. 参考文献行距过大（段落间距被撑开）。
8. 技术路线要一张**整页、多层、多分支**的总图。

**原则：顺着老师的改法走，只修硬错（病句、错字、逻辑自相矛盾、编号断裂）。** 老师的措辞本身是"评委会认的表达"，不要用自己的行文习惯去覆盖。只有当他删漏了主语、把"两条"写成"三种"、或留下"（）"这种空括号时才动。

落成一条可执行规则：

> **改动分三档**——①必改：错字、病句、空括号、编号断裂、前后矛盾、数据口径不一致；②可改：口语残留、逻辑连接词缺失；③不动：老师选择的句式、术语、分节方式、他自己加的判断句。

## 3. 项目命名（最容易被忽略、又最影响第一印象）

### 3.1 三类常见毛病

| 毛病 | 例子 | 后果 |
|---|---|---|
| 只有愿景没有对象 | "智绘未来——乡村振兴服务平台" | 评委不知你研究什么 |
| 技术堆砌 | "基于大模型+区块链+知识图谱的…" | 像课程作业，不像可交付的研究 |
| 名不副实 | 只有问卷 100 份却叫"系统""平台" | 答辩被追问即崩 |

### 3.2 可用的命名公式

```
〔品牌名（2–4 字，可造词）〕·〔实指对象〕——〔地域/场景〕〔做什么〕+〔用什么做〕
例：GIEP·地标智眸——山东乡村地理标志产业赋能与协同 AI 平台
     RCEP 智航——中小企业出海国别法律风险自检与合规自检平台
```

四个要件缺一不可：**对象（地理标志产业）＋ 地域（山东乡村）＋ 动作（赋能与协同）＋ 手段（AI 平台）**。

### 3.3 本例的三次演变（为什么最后这么定）

1. 早期："AI 驱动乡村地理标志产业赋能与协同平台"——只有手段+对象，没有地域，也没有"帮谁"。
2. 中期："山东乡村地理标志产业赋能与协同 AI 平台"——补齐地域与场景。
3. 定稿："GIEP・地标智眸——" 加前缀——**品牌名承担记忆点，副标题承担信息量**。评审在一堆申报书里翻，先记住"地标智眸"，再读副标题确认不是空壳。

### 3.4 三条硬约束

- **副标题必须一行放得下**（封面 12 磅、A4 三厘米边距，约 30–34 个汉字）。超了就砍形容词，不要缩字号——缩字号会在封面露出参差。
- **同一份材料里全称一致**。正文、图表题注、页眉、文件命名、GitHub 提交信息，一处简写就会让评委以为换了项目。
- **术语与学科门类对齐**。知识产权专业，一级门"法学"、二级类"法学类（0301）·知识产权（030102T）"，别写成"管理学"。

## 4. 从 22 份评委作品里学到的（真实评审语境）

手上有：22 份送审申报书 PDF + 一份《评审说明》。后者才是判据来源。

### 4.1 评审说明里真正被打分的四件事

1. **项目名称**：是否科学规范、能否体现研究内涵、有无过大或过小。
2. **项目必要性**：有无创意、有无价值、能否提升学生能力。
3. **项目可行性**：研究内容与过程描述是否真实可信；学校与导师水平能否支撑；学生团队是否具备相应知识能力。
4. **完成度**：材料是否像"已经想过一遍"的成品。

> 结论：**"可行性"是学生最容易丢分的一项**——不是写得少，而是写得不可信（数据无口径、方法无细节、风险无对策）。

### 4.2 高分件的共性（从样本里数出来的）

- **前 3 页定生死**：项目简介把"是什么、为什么、怎么做、做成什么样"四句说清，第 2 页就出现框架图。
- **图多而不乱**：医学/工程类样本平均 20–30 张图；社科类 10–20 张。图占版面 30%–40% 是舒适区；全是文字的页面评委直接跳读。
- **一图一义**：每张图只讲一件事，图注一句话点出结论，不写"示意图"三个字了事。
- **实证味**：带样本量、量表、信效度、前后测的稿子，明显比"对策建议型"高一档。
- **边界感**：主动写"本研究不做什么""样本局限在哪"，反而加分。

### 4.3 可以直接抄的排版习惯

- 一级节 5–9 个，二级不超过 6 个，三级最多到（1），**再往下就是没想清楚**。
- 正文小四、固定行距、首行缩进 2 字符；图注五号居中；表格三线。
- 每节开头先给结论句，不要"随着……的发展"。

### 4.4 图风（对标样本里的技术路线图）

对照样本（运动健康类）那张整页技术路线图，可提炼为：

- **分层带**：每一层左侧一条竖色带写层名（问题层／理论方法层／内容层／指标层／平台层／验证层／产出层）。
- **分支并列**：同一层内左右两条支线（本例：文本镜 / 田野镜），各自纵向推进，再汇合。
- **编号贯穿**：①—⑫ 跨层连续编号，读者可以按号找步骤。
- **回流虚线**：后一阶段推翻前一阶段假设时，用灰色虚线回到相应层，别用实线（会与主流程混淆）。
- **低饱和学术色**：一层一色相家族，白底细边，深灰字。

## 5. 编号体例：一、（一）、1.、（1）到底怎么排

模板给的是"标题不编号 + 内容分条"的骨架，实际提交必须自己补层级。**经验证可用的体例**：

```
（一）项目简介            ← 一级：宋体小四加粗，不缩进
（二）研究目的
    1.解释标准执行失效的机制   ← 二级：仿宋_GB2312 小四加粗
（三）研究内容
    1.政策与标准文本研究
        （1）……                ← 三级：宋体小四加粗
```

三条规则：

1. **一级用（一）不用"一、"**。因为模板的"一、基本情况""二、立项依据"是文档级编号（Word 自动列表），正文里再用"一、"会和它撞车。用户原话："内容里最大的应该是（一）"。
2. **章节标题本身不加编号**（项目简介／研究目的／…），与模板一致；编号从内容的第一层开始。
3. **字体分级**：一级宋体加粗、二级仿宋加粗、三级宋体加粗。这套"宋→仿宋→宋"的交替，是中文公文的传统层级区分法，比全用黑体更耐看。

**踩过的坑**：只改文字不改字体，会出现"层级换了、视觉还是平的"；只改字体不改编号，会出现"（一）下面直接跟（一）"。

## 6. 图表规范（本轮踩齐了）

| 规则 | 说明 |
|---|---|
| 题注在**图下**、**表上** | 图题统一"图N 标题"（单空格），表题"表N 标题" |
| 图号按**文档位置**重排 | 不要按字符串匹配，插入新图后一定全篇重编一次 |
| 图内不写标题 | 图里再写一遍标题会与题注重复，显得外行 |
| 插图宽度统一 | 整幅图 5.95in（≈15.1cm），截图/界面图可小，但一栏内别参差 |
| 三线表 | 顶线 1.5pt、表头下 0.75pt、底线 1.5pt，无竖线 |
| 配色家族 | 一张图内不超过 5 个色相；语义色固定（红=风险、蓝=主流程、灰=回流） |
| 单图单题注 | 两张图分别插会把后一张题注挤到下一页；需要并排就合成一张 |

**表 1（三套保护体系对照）、表 2（四类产品产业基础）** 是本例的两个"信息压缩"表——凡是能用表格替代 300 字排比的地方，一律改成表。

## 7. 参考文献：核验不是通读，是逐条"对字段"

### 7.1 流程

1. 从正文 `[n]` 反查条目，确认**每条都被引用过**（没引用的删掉或补引）。
2. 逐条查：**作者、题名、刊名、年、卷(期)、起止页**。五个字段任一不符即改。
3. 查不到的**不要"大概改改"**——直接换成同主题、可核实的文献，并把正文那句论断改写成新文献支持的表述。
4. 政策/标准类：查发布机构官网（局令编号、发布日期、施行日期、标准号与代替关系）。

### 7.2 本例改出来的六处（都是真实错误）

| 原条目问题 | 核实结果 |
|---|---|
| 题名用了网络首发名、卷期页缺失 | 吴方, 郭熙保. 家庭农场标准化生产的增收机制研究[J]. 华南农业大学学报(社科版), 2025, 24(5): 26-44 |
| 页码错（48-57） | 刘华军, 财经研究, 2011, 37(10): **49-58** |
| 缺起止页 | 陈嘉乐, 标准科学, 2023(8): **27-34** |
| 作者与论断对不上、查无实据 | 苏华等 → 换为 **董志勇, 李大铭, 李成明. 数字乡村建设赋能乡村振兴[J]. 行政管理改革, 2022(6): 39-46**，正文同步改写 |
| 标准号与实施日期不确定 | GB/T 17924—2025《地理标志产品质量要求标准编制通则》，2025-12-02 发布、2026-07-01 实施，全部代替 2008 版 |
| 地方文件无日期 | 山东省地理标志运用促进工程三年行动实施方案(2024—2026)，山东省市场监管局 2024-11-06 印发 |

### 7.3 新增内容必须配引

本例新增三段论述，各配一条可核实的经典文献，而不是只加"看起来相关"的：

- 政策执行落差（"执行失效不是孤例而是常态"）→ Pressman & Wildavsky, *Implementation*, 1973
- 基层执法者的信息依赖（"判定依赖可获得的现场信息与考核指标"）→ Lipsky, *Street-Level Bureaucracy*, 1980
- 量表编制与信效度 → 吴明隆《问卷统计分析实务》，重庆大学出版社，2010

> **纪律**：新增或改写任何一段带判断的文字，要么给出可核实文献，要么明确写成"本项目调研发现"，不允许悬挂式论断。

## 8. 脚本层面：本轮真实踩过的 8 个坑

**1. `set_text` 把图片段落清空了。**
为统一格式对某段调用"清空 runs 再写新文本"，而该段正是内嵌图片段——图片随 run 一起被删，最后只剩题注没有图。
→ 规则：**清空前先判 `p._p.findall('.//a:blip')`**，有图就跳过，或只改文本 run。

**2. 插图与题注顺序颠倒。**
`insert_picture` 用 `anchor.addnext(pic)`，紧接着 `clone_after(anchor, 题注)` 也插在 anchor 后，结果题注跑到图**上面**。
→ 规则：图与题注要么都 `addnext` 到同一锚点且**逆序插入**，要么显式 `pic.addnext(caption)`。

**3. 按固定索引批量改段落，插入操作后索引全偏移。**
先按 `P[15]`、`P[24]` 加小标题，后面再用旧索引取段落，结果把"国内研究三支"编号成 2./3./4.。
→ 规则：**一次遍历只做一件事**；需要二次改的，用**文本锚点**（`if "唯一短语" in p.text`）而不是索引。

**4. 段落带 Word 自动编号（numPr），又手写序号。**
渲染出"2. 1.法学研究…"这种双编号。
→ 规则：接手稿先扫 `pPr/w:numPr` 全部清掉，编号一律改为**文本**，可控可查。

**5. `firstLineChars="200"` 残留，标题被顶成"居中"观感。**
`pf.first_line_indent = Pt(0)` 只写 `w:firstLine="0"`，而 Word 优先认**字符型**缩进 `firstLineChars`。
→ 规则：设缩进 0 时必须 `del ind.attrib[qn('w:firstLineChars')]`。

**6. 换图按"上一段是不是题注"匹配，误伤邻居图。**
有一版图题在图上方，于是 `i-1` 命中邻近另一张图的题注，把那张图覆盖成了同一张（出现重复图 + 原图丢失）。
→ 规则：换图只按**这张图自己的题注**匹配（前后各看 1 段），且**每个关键字只允许命中一次**（用完即从候选集移除）。

**7. 只读文件保存报 `PermissionError`。**
微信收到的文件是 `-r--r--r--`，`shutil.copy` 会连权限一起复制，之后 `os.replace` 覆盖失败。
→ 规则：复制后立刻 `os.chmod(dst, 0o666)`；保存失败时"存临时文件 → chmod → replace"三段式兜底。

**8. 批量去空格把分隔符一起吃掉了。**
为满足"数字前后不留空格"，正则把"学    号 25314080118 专业班级…"里的分隔全删，变成"学    号25314080118专业班级"。
→ 规则：**只处理"数字↔汉字"相邻的空格**，标签与值之间用**全角空格**（U+3000）保留视觉间隔。

## 9. 可复用的四个代码片段

```python
# ① 安全替换段落文本（保留首行 run 的字体，不碰图片）
def set_text(p, text):
    if p._p.findall('.//' + qn('a:blip')):   # 图片段落跳过
        return
    rpr = copy.deepcopy(p.runs[0]._element.find(qn('w:rPr'))) if p.runs else None
    for r in list(p.runs):
        r._element.getparent().remove(r._element)
    run = p.add_run(text)
    if rpr is not None:
        run._element.insert(0, rpr)

# ② 插图 + 题注（图在上、题注在下，各一次 addnext）
def add_fig(anchor, img, caption, width_in=5.95):
    pic = doc.add_paragraph(); pic.alignment = WD_ALIGN_PARAGRAPH.CENTER
    pic.add_run().add_picture(img, width=Inches(width_in))
    anchor._p.addnext(pic._p)
    cap = copy.deepcopy(anchor._p); pic._p.addnext(cap)
    set_text(Paragraph(cap, anchor._parent), caption)

# ③ 图/表题注按位置重排（正则宽松，容忍空格与旧号）
for p in cell.paragraphs:
    m = re.match(r'^(图|表)\s*§?(\w*)§?\s*(\d+)?\s*(.+)$', p.text.strip())

# ④ 缩进归零（必须连同字符型缩进一起清）
ind = p._p.find(qn('w:pPr')).find(qn('w:ind'))
for a in ('firstLineChars', 'leftChars', 'firstLine', 'left'):
    if ind.get(qn('w:' + a)) is not None: del ind.attrib[qn('w:' + a)]
```

## 10. 表格字段模板（基本信息表）

三行长文本最容易被写成"口号"，可复用的写法：

**负责人科研经历**——按"项目—角色—具体动作—产出"写，一条一行：

```
1. 参与大创项目"RCEP 智航…"（校级立项晋升省级立项），承担国别规则梳理、资料检索与文稿撰写，
   熟悉项目申报、材料撰写与结题验收流程。
2. 2026 年暑期参加"三下乡"，围绕地理标志产品开展问卷发放与农户访谈，覆盖四类产品与多个产区，
   形成一手调研数据，构成本项目的数据基础。
```

**指导教师承担课题**——只写可核实的硬指标，不写"经验丰富、治学严谨"：

```
××，××学院教师，高级职业生涯规划师、心理咨询师。主持省级课题 1 项，参与省级课题 3 项；
以第二作者发表 SSCI、JCR 一区论文 1 篇；获××奖二等奖；指导学生获国家级、省级奖项多项。
```

**指导教师对本项目的支持**——分四条：研究指导 / 组织协调 / 过程管理 / 成果培育，每条给一个具体动作，不要写"全力支持"。

## 12. 下次照这个顺序走（一页速查）

1. **读批注 → 列需求**：把口语批注拆成"必改/可改/不动"三档，先固化再动手。
2. **定名**：对象＋地域＋动作＋手段，副标题一行放得下，全篇全称一致。
3. **对齐模板**：`pf probe` 两份基线比标题数与表数；确认正文是否在 1×1 表格里。
4. **理体例**：章节标题不编号；内容（一）→ 1. →（1）；字体宋/仿宋/宋交替。
5. **改文本**：按文本锚点定位，不用索引；改完查加粗、查空括号、查数字口径。
6. **补图**：先补"文字多图少"的段落（分级图、机制图、矩阵图、路线总图），一篇内的图要成家族。
7. **重排编号**：图、表全部按位置重编一次；正文"图 N"引用同步。
8. **核文献**：逐条五字段核对，改不动的换文献并改写论断。
9. **统一格式**：正文小四/固定行距/首行缩进；表内统一字号；清 numPr 与 firstLineChars。
10. **出 PDF 逐页看**：三处必看——图有没有被裁、题注有没有掉页、封面有没有折行。
