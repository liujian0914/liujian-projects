# GB/T 7714-2015 著录格式卡

> 直接抄。标点全部**半角**，条末不加多余标点。

---

## 一、类型标识

| 标识 | 文献类型 |
|---|---|
| `[M]` | 专著 |
| `[J]` | 期刊 |
| `[D]` | 学位论文 |
| `[R]` | 报告 |
| `[S]` | 标准 |
| `[C]` | 会议论文（论文集） |
| `[N]` | 报纸 |
| `[P]` | 专利 |
| `[G]` | 汇编 |
| `[Z]` | 其他 |
| `[DB/OL]` | 联机数据库 |
| `[EB/OL]` | 电子公告 / 网页 |
| `[J/OL]` | 联机期刊 |

---

## 二、模板

### 专著

```
[序号] 主要责任者. 题名[M]. 版本项. 出版地: 出版者, 出版年: 起止页.
```
```
[1] 刘华军. 地理标志的经济学分析[M]. 北京: 商务印书馆, 2022: 45-78.
```

### 期刊

```
[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页.
```
```
[2] 李海玲, 王小军. 地理标志农产品品牌建设的地方实践[J]. 农业经济问题, 2023, 44(8): 55-64.
```

> 卷号与期号都要有。只有期号时写 `2023(8): 55-64.`

### 学位论文

```
[序号] 主要责任者. 题名[D]. 保存地: 保存者, 年份.
```
```
[3] 熊肖雷. 地理标志农产品供应链协同机制研究[D]. 武汉: 华中农业大学, 2021.
```

### 报告

```
[序号] 主要责任者. 题名[R]. 出版地: 出版者, 出版年.
```
```
[4] RANGNEKAR D. The socio-economics of geographical indications[R]. Geneva: UNCTAD-ICTSD, 2004.
```

### 标准

```
[序号] 标准编号 标准名称[S]. 出版地: 出版者, 出版年.
```
```
[5] GB/T 17924—2008 地理标志产品标准通用要求[S]. 北京: 中国标准出版社, 2008.
```

### 会议论文

```
[序号] 析出责任者. 析出题名[C]//论文集责任者. 论文集名. 出版地: 出版者, 出版年: 起止页.
```

### 报纸

```
[序号] 主要责任者. 题名[N]. 报纸名, 年-月-日(版次).
```
```
[6] 苏华. 地理标志保护如何落到实处[N]. 农民日报, 2024-05-12(003).
```

### 电子资源

```
[序号] 主要责任者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```
```
[7] 国家知识产权局. 2024 年地理标志保护工作情况[EB/OL]. (2025-03-15)[2026-09-20]. https://www.cnipa.gov.cn/art/2025/3/15/art_1.html.
```

### 政策文件

有标准号的按 `[S]`；无标准号的按 `[EB/OL]` 或 `[Z]`：

```
[8] 中华人民共和国国务院. 地理标志产品保护规定[Z]. 2025-06-01.
```

## 三、责任者规则

**中文**：3 人以内全部列出，超过 3 人列前 3 位 + "，等"。

```
李海玲, 王小军, 张伟, 等.
```

**西文**：姓全大写，名缩写（不加点、不加空格，缩写间空一格）。

```
RANGNEKAR D.
MAERTENS M, SWINNEN J F M.
MENAPACE L, MOSCHINI G C.
```

**机构作者**：直接写机构名，不缩写。

```
国家知识产权局.
```

**无责任者**：题名前置。

## 四、正文标注

| 情形 | 写法 |
|---|---|
| 单条 | `……存在明显落差[3]。` |
| 连续多条 | `……已有较多讨论[3-5]。` |
| 不连续 | `……结论一致[3,7]。` |
| 引用具体页 | `……原文表述为……[3]45。` |
| 上标式（如刊物要求） | 将 `[3]` 设为上标 |

**标注放在句末标点之前**，这是中文习惯。

---

## 五、排序与编号

- 顺序编码制：按正文首次出现顺序编号，`[1]`、`[2]`……
- 编号必须连续，不留空号
- 中文文献与西文文献**混排**时按出现顺序编号，不要分组后重新从 1 编

---

## 六、常见错误

| 错误 | 正确 |
|---|---|
| 《农业经济问题》 | 农业经济问题（不加书名号） |
| LI Hailing | LI H L（名缩写） |
| 2023, 44: 55-64（缺期号） | 2023, 44(8): 55-64 |
| 55-64 页（加"页"字） | 55-64 |
| `[J/OL]` 无 URL | 补 URL 与引用日期，或改回 `[J]` |
| 编造 DOI | 删掉 DOI，或换成能查到的真实条目 |
| 条目整体居中 | 两端对齐 + 悬挂缩进（左 0.85cm，首行 −0.85cm） |

---

## 七、核实清单

每条文献打勾：

- [ ] 作者姓名与顺序（对照原文首页）
- [ ] 题名逐字（含副标题）
- [ ] 刊名全称
- [ ] 年、卷、期三项齐全
- [ ] 起止页码
- [ ] 该文献确实支撑所引观点

查不到就换一篇。**不编造卷期页码，不编造 DOI。**
