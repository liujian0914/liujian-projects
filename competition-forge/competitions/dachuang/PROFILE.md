# 国家级大学生创新创业训练计划（大创）

> 核实日期：2026-10-30
> 官方依据：[教育部《国家级大学生创新创业训练计划管理办法》](http://www.moe.gov.cn/srcsite/A08/s5672/201907/t20190724_392132.html)（教高函〔2019〕13 号）

## 一、这个比赛是什么

- **官方全称**：国家级大学生创新创业训练计划
- **俗称**：大创
- **⚠️ 名称澄清**：不是"大学生创新创业**大赛**"。它是**训练计划**——本质是**立项拿钱做项目**，
  分**国家级 / 省级 / 校级**三级，逐级申报。跟"中国国际大学生创新大赛（原互联网+）"是两个东西。
- **主管**：教育部高等教育司
- **项目类型**（三类，申报时要选）：

| 类型 | 内容 | 适合谁 |
|---|---|---|
| **创新训练项目** | 个人或团队，在导师指导下完成科研/创新性实验 | 偏研究的 |
| **创业训练项目** | 团队，做商业计划、可行性研究、模拟运营 | 偏商业的 |
| **创业实践项目** | 团队，真实注册公司并运营 | 已有实体的 |

> 用户此前的「GIEP·地标智眸」属**创新训练项目**（校级→省级立项），角色是**参与者，非负责人**。

- **周期**：一般 1 年（国家级 1–2 年）
- **经费**：国家级一般 1–2 万元/项（各校差异大，以本校通知为准）

## 二、评委怎么打分

大创是**立项评审**，核心问题只有一个：**"这笔钱给你，你能按期做出东西吗？"**

| 维度 | 权重 | 评委实际在找什么 |
|---|---|---|
| **可行性** | **最高** | 技术路线能不能走通？团队有没有相关能力？ |
| **创新性** | 高 | 和已有研究/产品比，新在哪 |
| **研究内容与目标** | 高 | 目标是否具体、可考核、不虚大 |
| **进度安排** | 中高 | 时间表是否合理，能不能在周期内完成 |
| **经费预算** | 中高 | 每一笔钱是否有依据，是否合规 |
| **团队与导师** | 中 | 分工是否合理，导师是否真能指导 |
| **预期成果** | 中 | 论文/专利/软著/样机，是否可实现 |

### 一句话总结大创的评审逻辑

> **"这事靠谱吗、你们做得完吗、钱花得值吗" > "这个想法有多宏大"**

**最常见的死法**：目标写得像国家战略（"赋能全国乡村振兴"），但没有一条能落地的技术路线。

## 三、材料形态

| 项 | 要求 |
|---|---|
| 主件 | 项目申请书 / 申报书 |
| 字数 | **1.2–1.6 万字**（"简明扼要"，不是越长越好） |
| 格式 | 学校发模板，**必须逐项对齐**，通常是表格嵌套式 |
| 附件 | 指导教师意见、学院推荐意见、团队简历 |
| PPT | **通常不需要**（校级答辩可能有，5–8 分钟） |
| 查重 | 有，且各校对"与往年立项重复"查得严 |

## 四、章节骨架（创新训练项目）

实测「GIEP·地标智眸」14.3MB 申请书，标准结构：

```
一、项目简介（300–500 字，一段话说清做什么）
二、研究目的与意义
    （一）研究目的
    （二）理论意义
    （三）实践意义
三、研究内容与目标
    （一）研究内容
    （二）研究目标
四、研究思路与方法
    （一）研究思路（配技术路线图）
    （二）研究方法
五、创新点与特色
六、进度安排（表格：时间 / 内容 / 阶段成果）
七、预期成果（论文/专利/软著/样机/报告）
八、经费预算（表格：科目 / 金额 / 用途 / 依据）
九、团队组成与分工
十、指导教师意见 / 学院意见
```

### 体例（经实战验证）

- **章节标题本身不编号**（写"研究目的与意义"，不写"二、研究目的与意义"）
- 编号从内容第一层开始：`（一）` → `1.` → `（1）`，最多三级
- 字体分层：一级宋体小四加粗、二级仿宋_GB2312 小四加粗、三级宋体小四加粗
- **正文常整体装在 1×1 表格里**——编辑时必须穿透表格，`doc.paragraphs` 会返回空

### 项目命名公式（实战总结）

```
品牌名 · 对象 —— 地域 + 动作 + 手段
```

例：「GIEP·地标智眸——山东乡村地理标志产业赋能与协同AI平台」

- 副标题必须**一行放得下**（12 磅约 30–34 字）
- 品牌名要有记忆点，但不能是生造词
- 破折号后必须交代**地域 + 做什么 + 用什么做**

## 五、常见失分点（按严重程度）

| 级别 | 失分点 | 为什么会失分 | 怎么避免 |
|---|---|---|---|
| 🔴 致命 | **目标虚大** | "服务全国""引领行业"，评委不信 | 目标限定在一个县/一个产业/一个环节，且可考核 |
| 🔴 致命 | **没有技术路线** | 只有想法没有做法 | 画技术路线图，每一步写清输入输出 |
| 🔴 致命 | 经费编不圆 | 设备费占 80% 却说不清买什么 | 每笔钱对应一个具体用途和依据 |
| 🟠 严重 | **进度排不出** | 一年要做 5 年的活 | 按月排，留缓冲；标出关键里程碑 |
| 🟠 严重 | 创新点空泛 | "首次提出""填补空白"没依据 | 写清"与 XX 相比，我们在 XX 上做了 XX" |
| 🟠 严重 | 团队分工虚设 | 5 个人写"共同研究" | 每人一个明确模块 + 交付物 |
| 🟡 中等 | 预期成果不可实现 | 一年发 3 篇 SCI | 本科生一年 1 篇普刊或 1 项软著更可信 |
| 🟡 中等 | 与往年立项重复 | 查重查得到 | 选题前查本校往年立项清单 |
| ⚪ 轻微 | 排版不统一 | 目录页码错、表格跨页裁字 | `pf qa` 一次查完 |

## 六、与其他赛道的区别

| | 大创 | 大挑 |
|---|---|---|
| 本质 | 项目**立项** | 成果**竞赛** |
| 核心问题 | 能不能做成 | 做出来了什么 |
| 时态 | 将来时（要做什么） | 完成时（做了什么） |
| 数据要求 | 有预调研更好，可以没有 | **必须有真调研** |
| PPT | 通常不要 | 必需，决胜 |
| 字数 | 1.2–1.6 万 | 2 万以上 |

**最容易搞错的**：把大创写成大挑（通篇是"我们调研发现"，但没有"我们要做什么、怎么做、什么时候做完"）。
大创的落脚点永远是**计划**。

## 七、时间节点（参考，以本校通知为准）

- 校级申报：一般 3–4 月
- 省级推荐：5–6 月
- 国家级立项：7–9 月
- 中期检查：次年 3–4 月
- 结题验收：次年 9–10 月

## 八、写作口径提醒

1. **用"将"不用"已"**——大创写计划，不要写成已完成。
2. **每个目标都要可考核**。写"完成 1 份 3 万字的调研报告、1 篇省级期刊论文、1 项软件著作权"，
   不写"取得丰硕成果"。
3. **技术路线图是加分项**。用 `pf chart --spec` 的 framework 类型画。
4. **经费要有依据**。差旅费写"调研 3 次 × 5 人 × 800 元 = 12000 元"，不写"差旅费 12000 元"。
5. **承认风险**。写一段"可能的风险与应对"，评委会觉得你想清楚了。
