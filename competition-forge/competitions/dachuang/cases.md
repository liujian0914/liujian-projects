## 三、评审偏好（从 22 份评委样本书 + 《评审说明》提炼）

| 评委关心 | 具体表现 | 怎么写 |
|---|---|---|
| **能不能结题** | 目标是否可考核 | 每个目标都写成"完成 X 份报告/1 篇论文/1 项软著" |
| **技术路线清不清楚** | 有没有路线图 | 画分层流程图，每步有输入输出 |

| **创新在哪** | 有没有对比 | "与 XX 相比，我们在 XX 上做了 XX" |

## 五、图表规范（七条）

1. **图宽统一 12.2cm**（A4 三厘米边距的正文宽）
2. **单图单题注**——两张图分别插会把后一张题注挤到下一页
3. **题注在图下方**，格式"图 N 标题"
4. **表题在表上方**，格式"表 N 标题"
5. **正文必须有"如图 N 所示"的引用**
6. **配色要有家族**——同一类图同一组色，不同类图不同色相家族
7. **语义色不能动**——绿=合规、红=风险、蓝=授权等级

## 六、文献核验（16 条，纠错 6 处）

**五字段核验法**：每条文献必须核实

| 字段 | 核什么 |
|---|---|
| 作者 | 姓名拼写、顺序、人数 |
| 刊名 | 全称、是否核心期刊 |
| 年份 | 出版年 |
| 卷期 | 卷号、期号、页码 |
| DOI | 能否打开 |

**实测纠错 6 处**：
- 作者名拼错
- 刊名用了简称
- 年份错（提前一年）
- 卷期号缺失
- 页码错误
- 文献根本不存在（AI 幻觉）

**结论**：**AI 生成的文献必须逐条联网核实**，查不到就换一篇，绝不编造。

## 七、8 个脚本坑（写脚本时必看）

| # | 坑 | 症状 | 解法 |
|---|---|---|---|
| 1 | 用 `id(el)` 给 lxml 元素去重 | 15k 字文档只统计到 668 字，**静默出错** | 改 `body.iter(qn("w:p"))` |
| 2 | 清空 runs 时把图片吃了 | 图没了 | 清空前判断 run 里有没有 `drawing` |
| 3 | 题注插到图上方 | 图和题注分家 | 用 `addnext` 不用 `addprevious` |
| 4 | 索引偏移 | 插入后后续段落错位 | 倒序插入或重新遍历 |
| 5 | numPr 双编号 | 出现"1. 一、" | 检查段落是否既有 numPr 又手写了编号 |
| 6 | firstLineChars 残留 | 缩进不对 | 显式设 `firstLineChars=0` |
| 7 | 换图误伤邻居图 | 换了 A 图 B 图也变了 | 按 `rId` 精确定位，不要按顺序 |
| 8 | 只读文件 PermissionError | 写入失败 | 先检查 `~$xxx.docx` 锁文件 |

## 八、可复用片段

### 8.1 穿透表格遍历正文

```python
from docx.oxml.ns import qn

def iter_all_paragraphs(doc):
    """穿透表格遍历所有段落（中文申报书常把全文塞进 1×1 表格）"""
    body = doc.element.body
    for p in body.iter(qn("w:p")):
        yield p
```

### 8.2 克隆模板段落

```python
import copy

def clone_paragraph(src_p, after_p):
    """克隆一个段落并插到 after_p 之后，格式完全一致"""
    new_p = copy.deepcopy(src_p._p)
    after_p._p.addnext(new_p)
    return new_p
```

### 8.3 按位置重排图号

```python
def renumber_figures(doc):
    """按文档位置重排图/表题注，不靠字符串匹配"""
```
