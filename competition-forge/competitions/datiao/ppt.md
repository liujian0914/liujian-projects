# 大挑 PPT 策略

> 通用方法见 `ppt/PLAYBOOK.md`。本文件只写大挑特有的部分。

## 一、定位

**成果答辩**：讲"我们已经发现了什么"，不是"我们打算做什么"。

大挑是现场答辩打分，PPT 质量直接影响成绩——这是**唯一一个"PPT 不好会直接输"的赛道**。

## 二、硬指标

| 项 | 值 | 依据 |
|---|---|---|
| 页数 | **18–22 页** | 8 份获奖作品实测：省铜 11、省银/省特 19–25、省金 18–37 |
| 时长 | 8–10 分钟讲 + 5 分钟问答 | 常规 |
| 风格 | 田园实景 / 商务数据 / 人文纪实 / 学术简约 | 按主题选，见 `ppt/PLAYBOOK.md` 第三节 |
| 动画 | **必需**，关键页有、普通页无 | 见下 |

**页数下限 18 页是硬线**：省铜 31 号只有 11 页，是最主要的失分原因之一。

## 三、必有的两页（决胜页）

### 3.1 调研规模数据墙（放前 1/3）

这是大挑 PPT 的**命门**。评委第一反应就是"你去了没有、问了多少人"。

**做法**：一页放 6–8 个超大数字 + 一行小字说明 + 照片墙。

实测省金 11 号作品的原版数据：

```
入户调查 532 户    累计天数 271 天    访问高管 58 人
调研县区 16 个     问卷回收率 85%     问卷总数 1 万余份
累计时长 896 小时  调研单位 52 个
```

**你的版本必须换成自己的真实数字**。没有这么多就写真实的少一点，**不要编**。

**版式**：
- 数字用 48–72pt，粗体，主色
- 说明文字 14–16pt，灰色
- 右侧或下方放 6–12 张调研现场照片（小图，网格排列）
- 顶部一句标题：「调研规模」或「我们走过的路」

### 3.2 自创框架图（放后 1/3）

大挑获奖作品几乎都有**自己的分析框架**，不是套现成理论。

实测案例：
- 12 号：TICE 新型发展理念（写进了副标题）
- 7 号：庭院经济+ 四维模型（组织形式 / 融资方式 / 运营模式 / 宣传推广）
- 11 号：三层框架（外层框架 / 发展现状 / 问题总结与政策建议）

**做法**：
- 圆形 / 四象限 / 分层三角形，比表格好记
- 框架名要朗朗上口，且**贯穿全篇**（封面副标题 → 目录 → 正文 → 结论）
- 用 `pf chart --spec` 的 `framework` 类型画

## 四、骨架选择

| 你的优势 | 用哪个骨架 |
|---|---|
| 调研规模大、数据多 | **骨架 A（数据型）** |
| 有自创概念/理论 | **骨架 B（框架型）** |
| 两者都有 | A 为主，框架图放 P18 |

完整骨架见 `ppt/PLAYBOOK.md` 第二节。

## 五、动画纪律

大挑答辩时间紧（8–10 分钟），动画是**控制节奏**的工具，不是炫技。

| 页 | 动画 | 时长 |
|---|---|---|
| 封面 | 标题淡入 + 副标题延迟 | 0.5s + 0.3s |
| 目录 | 6 条依次飞入 | 每条 0.3s |
| 章节页 | 章节号放大 + 标题右滑 | 0.6s |
| **数据墙** | **8 个数字依次计数/弹出** | 每个 0.2s |
| 图表页 | 柱/线从左到右生长 | 0.8s |
| 框架图 | 分块依次出现 | 每块 0.3s |

**总动画时长控制在 40 秒内**。

**禁止**：旋转、弹跳、闪烁、全篇动画、切换效果混用。

## 六、视觉风格建议

按主题选：

| 主题 | 风格 | 配色 |
|---|---|---|
| 乡村振兴、农业、地理标志、生态 | 田园实景风 | 深绿 `#2D5016` + 暖金 `#C8A45C` |
| 金融、经济、产业分析 | 商务数据风 | 墨绿 `#1B5E20` + 亮绿/橙 |
| 文化、中医药、红色专项 | 人文纪实风 | 暖棕 `#6D4C41` + 金 |
| 说不清 / 通用 | 学术简约风 | 深灰 `#333` + 单点红 `#C62828` |

**地理标志主题推荐田园实景风**：深绿主色 + 暖金强调 + 白底或实景照片。

## 七、配图纪律

| 图类型 | 怎么做 | 红线 |
|---|---|---|
| 封面实景 | **自己拍** | 不能用 AI 生成 |
| 调研现场照片墙 | **自己拍** | 不能用 AI 生成 |
| 政策文件截图 | 官方原文截图 | 不能伪造 |
| 数据图 | `pf chart` / `figures/SCIENCE-PLOT.md` | 数据必须真实 |
| 框架图 | `pf chart --spec` framework | — |
| 章节页背景/纹理 | AI 生图（本机 SD 免费） | 只能是装饰 |
