## 〇、一句话结论

> **获奖作品看起来"不花哨"。71% 的页面是白底简约，平均饱和度只有 13.8%。**

这跟很多人对"竞赛 PPT 要炫"的想象相反。数据说明：
**评委在有限时间里要抓信息，不是欣赏设计。** 越是把视觉噪音压下去、把数据顶上来，越占优势。

## 一、量化结果（24 张 PPT 页面实测）

### 1.1 风格分布

| 风格 | 页数 | 占比 | 特征 |
|---|---|---|---|
| **白底简约** | 17 | **71%** | 浅色占比 >55%，饱和度 <18% |
| 实景/复杂背景 | 3 | 12% | 深色占比 >45%，整页照片 |
| 浅色留白 | 3 | 12% | 浅色 40–55%，中等密度 |
| 鲜艳主题色 | 1 | 4% | 饱和度 >28% |

**关键**：**七成页面是白底**。只有封面和章节页用整幅实景图。

### 1.2 整体指标

| 指标 | 数值 | 含义 |
|---|---|---|
| 平均浅色占比 | **64.7%** | 大面积留白/白底 |
| 平均饱和度 | **13.8%** | **极低**，接近灰阶 |
| 平均边缘密度 | 18.11 | 中等偏上，信息有密度但不拥挤 |

**饱和度 13.8% 是什么概念**：纯黑白是 0%，这张纸上的普通印刷文字大约 5–10%，
彩色照片约 40–60%。**13.8% 意味着"几乎只有标题和强调色是彩色的"**。

### 1.3 高频主色（跨页面统计）

| 色值 | 出现页数 | 判断 |
|---|---|---|
| `#F0F0F0` | 23 | **白色/浅灰背景**（几乎每页都有） |
| `#E0E0E0` | 10 | 浅灰卡片/分隔 |
| `#D0D0D0` | 7 | 灰阶文字/线条 |
| `#F0F0E0` | 6 | 米白（暖调背景） |
| `#E0F0E0` | 6 | 极浅绿（绿色系作品的底纹） |
| `#40A040` | 4 | **主绿色**（强调色） |
| `#303030` | 2 | 深灰文字 |
| `#503000` | 2 | 深棕（中医药/人文主题） |

**结论**：配色结构极其统一 —— **`#F0F0F0` 白底 + `#303030` 深灰文字 + 一个主色（绿/棕）**。
没有第三、第四个主色。

## 二、四套实际配色方案（从案例提取，可直接用）

### 2.1 田园绿（地理标志/乡村振兴首选）

**来源**：12 号鲁山县（省金）、7 号庭院经济（国铜）

```yaml
背景: "#FFFFFF" / "#F0F0E0"   # 纯白或极浅米
正文: "#303030"                # 深灰，不用纯黑
主色: "#2D5016" → "#40A040"    # 深绿到中绿
强调: "#C8A45C"                # 暖金（数字/关键结论）
辅助: "#E0F0E0"                # 极浅绿（卡片底/表头）
```

**用在哪**：封面绿植实景、章节页浅绿装饰、数据图主色用 `#40A040`。

### 2.2 商务墨绿（经济/金融/产业分析）

**来源**：11 号绿色金融（省金）

```yaml
背景: "#FFFFFF"
正文: "#303030"
主色: "#1B5E20"     # 墨绿
次色: "#4CAF50"     # 亮绿（图表第二系列）
强调: "#FF9800"     # 橙（对比数据/警示）
```

**特征**：图表用双色（绿 + 橙）做对比，数据墙数字用墨绿。

### 2.3 人文暖棕（文化/中医药/红色）

**来源**：31 号亳州中医药（省铜）、8 号红色专项（国铜）

```yaml
背景: "#FAF7F2"     # 暖白
正文: "#3A3A3A"
主色: "#6D4C41"     # 深棕
强调: "#C8A45C"     # 金
辅助: "#E8DDD0"     # 浅米
```

**特征**：封面用中药材/红色实景，正文用圆形主视觉。

### 2.4 学术极简（通用最安全）

**来源**：18 号莱西经验（省金）

```yaml
背景: "#FFFFFF"
正文: "#333333"
主色: "#333333"     # 深灰
强调: "#C62828"     # 单点红（只用于关键数字）
辅助: "#F5F5F5"     # 浅灰卡片
```

**特征**：几乎全灰阶，只有一两个数字是红的。**这是最不容易出错的选择**。

## 三、计划书的版式风格（4 份实测）

### 3.1 封面（统一规律）

| 要素 | 做法 | 案例 |
|---|---|---|
| 主视觉 | **整幅实景照片**（田园/药材/建筑） | 12、7、31 |
| 标题 | 大号，2–3 行，压在图上 | 全部 |
| 副标题 | 破折号引出，说明方法/对象 | 全部 |
| 装饰 | 绿色叶片/枝条装饰边角 | 12 |
| 圆形构图 | 主视觉做圆形蒙版，标题压在圆上 | 7、31 |

**两种封面范式**：
- **A 全幅实景**（12 号）：整页绿植梯田照，标题直接压上，加叶枝装饰
- **B 圆形主视觉**（7、31 号）：中央一个圆形照片/图形，标题环绕，留白多

### 3.2 正文页

| 要素 | 做法 |
|---|---|
| 栏数 | **单栏**（不双栏） |
| 字号 | 小四（12pt），1.5 倍行距 |
| 标题 | 深绿/深棕加粗，居中或左对齐 |
| 边框 | **装饰性边框**（12 号有绿色藤蔓边角） |
| 页脚 | 统一页码 + 项目名 |
| 图 | 宽约 12–14cm，居中，图题在下 |
| 表 | 三线表，表题在上 |

### 3.3 目录页（7 号最规整）

```
一、项目概述 .......................... 1
  1.1 政策解读 ........................ 1
  1.2 战略解读 ........................ 1
...
```
- 一级标题加粗，二级缩进
- 点线引导页码
- **不带装饰，纯文字**——这是最专业的做法

### 3.4 摘要页

7 号有独立摘要页：正文 + **关键词**（3–5 个，分号隔开）。

**建议**：2 万字以上的调查报告**必须**有摘要和关键词。

## 四、图型风格（从案例归纳）

### 4.1 数据图的三条规律

1. **无网格线或极淡网格**。案例里的柱状图/折线图基本都是白底无网格。
2. **单色或双色**。不出现彩虹色，最多主色 + 强调色。
3. **数字标注在图上**，不用图例去猜。

### 4.2 示意图（架构/框架）

| 案例 | 做法 |
|---|---|
| 7 号庭院经济 | 绿色圆角标签 + 图标，6 种方法竖排 |
| 11 号绿色金融 | 三层框架图（外层/现状/建议），细线框 |
| 12 号 TICE | 手绘箭头指向问题点 |

**规律**：**用圆角矩形和细线**，不用立体/阴影/渐变。

### 4.3 照片墙

**11 号**在调研规模页右侧放了 12 张小照片（约 3×4 网格）。

**用法**：证明"我真的去了"。**必须是自己拍的**，不能 AI 生成。

### 4.4 图标

- 线性图标（细线），不用填充彩色图标
- 统一风格（全线性或全面性，不混用）
- 尺寸统一（24/32/48 px）

## 五、反面清单（实测哪些做法没拿高分）

| 做法 | 问题 | 出现在 |
|---|---|---|

| 通篇无调研规模数字 | 证明不了工作量 | 31 号（省铜） |

## 六、给本项目的落地规则

### 6.1 做 PPT 时

```yaml
默认: 白底简约（71% 的获奖页面是这个）
背景: #FFFFFF 或 #F0F0E0
文字: #303030（不用纯黑 #000000）
主色: 一个（按主题选田园绿/商务墨绿/人文暖棕）
强调: 一个（暖金或橙）
饱和度控制: 全篇平均 <20%
实景图: 只用在封面、章节页、照片墙
数据图: 无网格、单/双色、数字标在图上
```

### 6.2 做文档时

```yaml
封面: 整幅实景照 或 圆形主视觉
正文: 单栏、小四、1.5 倍行距
标题: 深绿/深棕加粗
图宽: 12–14cm 统一
表格: 三线表，表题在上
摘要: 2 万字以上必写，含 3–5 个关键词
目录: 纯文字 + 点线，不加装饰
```

## 七、诚实交代分析边界

| 项 | 情况 |
|---|---|
| 样本量 | 24 张 PPT 页面 + 16 张文档页面，**不是全部**（全量约 300+ 页） |
| 抽取方式 | 每份案例取前 6 页（封面/目录/前几章），**后段未覆盖** |
| 量化方法 | 16 级颜色量化 + 明度/饱和度/边缘密度，**是近似而非精确取色** |
| 风格分类 | 按阈值规则判定，**边界案例可能误判** |
| 未分析 | 动画效果（PDF 抽帧看不到）、字体名称、版式精确尺寸 |

**结论可信度**：风格分布（白底简约占多数）与配色结构（白底+深灰+单主色）**可信**，
因为跨多份案例一致；具体色值可能有 ±8 的量化误差，用前建议目测校准。

需要精确取色时，用 `_analysis/visual_style_raw.json` 里的原始数据，或直接对原图取色。
