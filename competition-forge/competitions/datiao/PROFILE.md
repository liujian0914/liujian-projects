# "挑战杯"全国大学生课外学术科技作品竞赛（大挑）

> 核实日期：2026-10-30
> 官方评审规则依据：[挑战杯官网评审规则](https://2025.tiaozhanbei.net/)（逐年更新，用前先核当年版本）

## 一、这个比赛是什么

- **官方全称**："挑战杯"全国大学生课外学术科技作品竞赛
- **俗称**：大挑
- **主办**：共青团中央、中国科协、教育部、中国社科院、全国学联 + 承办高校
- **层级**：校赛 → 省赛 → 国赛（三级）
- **举办周期**：每两年一届（奇数年国赛）
- **⚠️ 最易混淆**：「小挑」是**"挑战杯"中国大学生创业计划竞赛**，另一个赛事。大挑比的是**学术科技作品**，不是创业计划。

### 参赛作品分类（三条赛道，评审标准完全不同）

| 类别 | 内容 | 要不要 PPT |
|---|---|---|
| **自然科学类学术论文** | 理工科原创研究 | 要 |
| **哲学社会科学类社会调查报告** | 社科类实地调研 | **要，且是决胜环节** |
| **科技发明制作** | A 类（科技含量高）/ B 类（实用价值高） | 要 |
| 红色专项活动 | 传承红色基因主题实践 | 一般不要 |

> 用户目前手上的「地理标志」主题属于**哲学社会科学类社会调查报告**。下面所有判断默认按这一类写。

## 二、评委怎么打分

哲学社会科学类社会调查报告的核心评审维度（按权重排）：

| 维度 | 权重感觉 | 评委实际在找什么 |
|---|---|---|
| **选题价值** | 高 | 这个题目值不值得调研？有没有现实意义？是不是"真问题" |
| **调研方法与过程** | **最高** | 样本怎么来的？多少份？跑了多少地方？访谈了谁？—— **这是大挑的命门** |
| **数据真实性与分析深度** | 高 | 数据能不能追溯？分析是不是只停在描述统计 |
| **结论与对策的可行性** | 中高 | 建议是不是空话？能不能落地 |
| **创新性** | 中 | 有没有自己的分析框架/概念（如 TICE 理念、庭院经济+） |
| **规范性** | 中 | 格式、引注、图表规范 |

### 一句话总结大挑的评审逻辑

> **"你去了没有、问了多少人、数据靠不靠得住" > "你文笔好不好"**

从 8 份获奖 PPT 实测印证（见 `cases.md`）：省金作品无一例外都在**前 5 页内亮出调研规模数字**——
「532 户 / 271 天 / 896 小时 / 52 个调研单位」「累计发放问卷 852 份、有效回收 851 份」。

## 三、材料形态

| 项 | 要求 |
|---|---|
| 主件 | 社会调查报告（正文） |
| 字数 | **2 万字以上**（省金作品普遍 2–3 万；国赛更多） |
| 格式 | 一般 A4、宋体小四、1.5 倍行距；具体看当年通知 |
| 附件 | 问卷样张、访谈提纲、调研照片、数据表、获奖/实践证明 |
| PPT | **必需**，答辩用，通常 8–10 分钟汇报 + 5 分钟问答 |
| 查重 | 严格，且**数据造假是一票否决** |

## 四、章节骨架（哲学社会科学类社会调查报告）

实测 4 份获奖作品的目录结构，归纳出**两个主流范式**：

### 范式 A · 六段式（最通用，省金 12 号作品用）

```
第一章  研究背景与意义
第二章  研究思路与方法
第三章  <研究对象>发展现状
第四章  <研究对象>存在问题
第五章  对策建议 / 模式设计
第六章  结论与展望
```

### 范式 B · 调研流程式（数据型作品用，省金 11 号作品用）

```
01  调查背景
02  调查思路
03  调查过程      ← 重点：调研设计、样本、时间跨度
04  调查结果
05  对策建议
06  调查成果      ← 成果清单：论文、专利、采纳证明
```

### 范式 C · 递进式（有自创框架的作品用，省金 12 号、国铜 07 号用）

```
绪论 → 相关概念及学理基础 → 现状调研（供给侧）→ 需求调研 → 模式设计 → 实施情况
```

**选哪个**：
- 有自创分析框架 → 范式 C
- 调研规模是最大卖点 → 范式 B
- 说不清 → 范式 A（最稳）

### 每一节该写多少

以 2.5 万字总量估：

| 章节 | 字数 | 占比 |
|---|---|---|
| 背景与意义 | 3000 | 12% |
| 思路与方法 | 3000 | 12% |
| 现状（含数据） | 8000 | **32%** |
| 问题分析 | 5000 | 20% |
| 对策建议 | 5000 | 20% |
| 结论 | 1000 | 4% |

**现状+问题 = 52%**，这是数据密度最高的部分，也是评委最看的地方。

## 五、常见失分点（按严重程度）

| 级别 | 失分点 | 为什么会失分 | 怎么避免 |
|---|---|---|---|
| 🔴 致命 | **数据来源说不清** | 评委第一问就是"你这个数怎么来的" | 每个数字标口径：样本量、时间、地点、方法 |
| 🔴 致命 | **样本量太小或抽样不科学** | 几十份问卷撑不起"全国/全省"结论 | 样本量与结论范围匹配；小样本就限定结论边界 |
| 🔴 致命 | 抄袭/数据造假 | 一票否决 | 绝不编数据；文献逐条核实 |
| 🟠 严重 | **只有描述统计，没有分析** | 像一份问卷汇总，不像研究 | 至少做交叉分析、相关性、或质性编码 |
| 🟠 严重 | 对策建议空泛 | "加强宣传、完善机制"这类放之四海皆准的话 | 每条建议要有：谁来做、怎么做、需要什么条件 |
| 🟠 严重 | 选题太大或太小 | "中国乡村振兴研究"做不完；"某村某户"没价值 | 中等尺度：一个县/一个产业带/一个模式 |
| 🟡 中等 | 没有理论支撑 | 通篇是现象罗列 | 至少一个分析框架（自建也行，如 TICE） |
| 🟡 中等 | 图表不规范 | 图无编号、无来源、配色花 | 见 `references/03-figures.md` |
| 🟡 中等 | 参考文献凑数 | 全英文旧文献、与正文不对应 | GB/T 7714 + 逐条核实 + 正文有引用 |
| ⚪ 轻微 | 排版不统一 | 目录页码错、表格跨页裁字 | `pf qa` 一次查完 |

## 六、与其他赛道的区别

| | 大挑 | 大创 | 小挑 |
|---|---|---|---|
| 比什么 | 已有**成果** | 项目**计划** | **创业计划** |
| 核心材料 | 调查报告 2 万字+ | 申请书 1.2–1.6 万字 | 商业计划书 |
| 数据要求 | **必须有真调研** | 有最好，可以没有 | 市场数据 |
| PPT | 必需，决胜 | 通常不要 | 必需，路演 |
| 评委关注 | 方法、数据、价值 | 可行性、经费、进度 | 商业模式、团队 |

**最容易搞错的**：把大挑写成大创（通篇讲"我们要做什么"，没有"我们做了什么"）。
大挑的所有内容都必须建立在**已经完成的调研**之上。

## 七、时间节点（参考，以当年通知为准）

- 校赛：一般 3–5 月
- 省赛：6–8 月
- 国赛：10–11 月
- 每两年一届，**奇数年**有国赛

## 八、写作口径提醒

1. **全篇用"调研发现"而不是"我们认为"**——有数据支撑才叫发现。
2. **每一个百分比都要有分母**。写"78.3%（N=842）"不是"78.3%"。
3. **承认局限**。样本偏差、地域限制、时间跨度不足，主动写出来反而加分。
4. **对策要能落地**。写成"建议 XX 部门在 XX 环节做 XX"，不要写成口号。
5. **附件要给全**。问卷、提纲、照片、原始数据表——这是"我真的去了"的证据。
