# 07 · 去 AI 味

> 申报书、申请书、研究报告属于**正式事实性文本**。去 AI 味不是把文字改口语，而是删掉那些"看起来很努力、其实没信息"的写法。

这一点必须先说清：把学术文本改成"说白了""咱就是说"，是另一种失败。读者是评委，他要的是**判断和证据**，不是亲切感。

---

## 一、AI 味到底是什么

不是某个词的问题，是四种行为模式：

| 模式 | 表现 | 本质 |
|---|---|---|
| **铺垫代替陈述** | "随着…的不断发展""值得注意的是" | 不敢直接下判断 |
| **拔高代替论证** | "深刻变革""全方位赋能""范式重构" | 没有数据，用形容词凑 |
| **节奏代替逻辑** | 三句同构、四字格连排、每段一样长 | 结构整齐但没有推进 |
| **格式代替内容** | 满屏破折号、粗体、项目符号 | 用排版制造层次感 |

判断标准：**把这段的形容词和连接词全删掉，还剩多少信息？** 剩不到一半，就是 AI 味。

---

## 二、五类痕迹与前/后对照

### A · 铺垫代替陈述

**特征**：开头先铺垫时代背景、先承认复杂性、先来一句"不难发现"。

| 改前 | 改后 |
|---|---|
| 随着乡村振兴战略的不断深入推进，地理标志农产品品牌建设日益受到重视。 | 2024 年山东省地理标志产品产值 1,860 亿元，但四类主产区农户的标准执行率仅 40%。 |
| 值得注意的是，现有研究多聚焦于制度设计层面，对执行环节关注不足。 | 现有研究集中在制度设计（李海玲，2023；刘华军，2022），执行环节的实证材料仍少。 |
| 为了更好地服务于地方产业发展，本项目旨在通过构建平台来推动…… | 本项目做三件事：建标准库、做执行评估、出治理建议。 |

**改法**：删铺垫，第一句就给事实或判断。背景段的价值只在"给出可核对的时点与文件"。

---

### B · 公式化节奏

**特征**：四项以上并列连排、每段一样长、"不仅…而且"连锁。

| 改前 | 改后 |
|---|---|
| 本项目具有重要的理论意义、现实意义、推广价值和社会效益。 | 项目的直接产出是一套可复用的六维评估量表；能否推广到其他品类，取决于抽样框是否可复制（第四章讨论）。 |
| 不仅提升了农户的认知水平，而且增强了执行能力，同时还促进了产业协同。 | 干预八周后，认知分从 41.2 升到 78.6，执行分从 38.5 升到 66.4；产业协同没有显著变化。 |

**注意**：数据分类的枚举（"普通农户、家庭农场、合作社、龙头企业"）是**正常**的，不要为了"去 AI 味"把分类拆散。要改的是**句式层面的四连排**。

---

### C · 拔高与空泛归因

**特征**：形容词顶替数字；"业内普遍认为"却不说谁认为。

| 改前 | 改后 |
|---|---|
| 这对地方产业发展具有深远影响。 | 按现有转化率推算，标准执行率每提高 10 个百分点，四类产品年增收约 2,300 万元。 |
| 业内普遍认为，地理标志的保护效果取决于监管强度。 | Menapace 与 Moschini（2012）用美国市场数据测算，监管强度每提高一档，溢价留存率提高 6–9 个百分点。 |
| 相关研究表明该模式具有较强可行性。 | 删除。或补：谁、哪年、什么样本、什么结论。 |

**改法**：形容词换成数字；归因必须点名"谁、哪年、什么样本"。查不到出处，删掉这个判断。

---

### D · 排版痕迹

| 症状 | 处理 |
|---|---|
| 破折号一篇十几处 | 压到 3 处以内。项目名与副标题里的「——」是规范用法，不算 |
| 满屏加粗 | 加粗只给真正的结论句，一段最多一处 |
| 全是项目符号 | 关键论证要成句成段，bullet 只用于并列事项 |
| markdown 符号残留（`**`、`---`） | 清掉，正式文档用样式不用符号 |

---

### E · 中文特有的机器腔

| 症状 | 改法 |
|---|---|
| 进行+名词（"进行了深入的研究"） | 直接用动词：研究、分析、梳理 |
| 通过…的方式 | 改成"用 X 做 Y" |
| 基于…的基础上 | 语病，二选一："基于 X"或"在 X 的基础上" |
| 被字句堆叠（"被实现为…被持续记录…"） | 指出施动者，或改主动 |
| 的的不休（三个"的"连用） | 拆句 |
| 连续三段用"此外/同时/因此"开头 | 说明段间没有真实逻辑关系，重排论证顺序 |

---

## 三、五个改写动作

按顺序做，不要一上来就润色字句。

### 1. 删

先删这些：铺垫句、总结句、"综上所述"、"由此可见"、万能价值句（"具有重要意义的"）、重复的解释。

一份 1.5 万字的申报书，删掉纯废话通常能减 800–1,500 字，且读起来更快。

### 2. 换

形容词换数字。这是单条收益最高的动作：

```
显著提升   →  提高了 27.4 个百分点
大量样本   →  103 份有效样本
广泛认可   →  6 个产区中 5 个复购
较强可行性 →  两个模块已在 2 个合作社跑通，连续 8 周无中断
```

### 3. 补

补三样东西：**口径**（数据怎么来的）、**边界**（什么情况下不成立）、**机制**（为什么会这样）。

"认知高、执行低"这句话，AI 味版本到此为止。人写版本会补：

> 认知 75.3 分、执行 40.2 分，落差 35.1 分。落差的可能机制是：标准文本以"符合性"为导向，而农户决策以"成本—收益"为导向，二者在缺少可核对的时间序列时无法自洽。这一解释可被检验：若干预后执行分上升而认知分不变，说明约束在成本侧；反之在信息侧。

### 4. 拆

超过 60 字的长句拆成两句。中文一句话塞三个分句，读者要回读。

### 5. 并

短段落合并成有推进关系的段落。一段一句的排版看着清爽，实际没有论证。

## 四、不同文体的尺度

| 文体 | 保留正式度 | 允许的口语化 | 说明 |
|---|---|---|---|
| 学术论文 | 高 | 几乎没有 | 被动句、名词化表达都合规 |
| 项目申报书 | 高 | 极少量（"没做成的地方"这类坦白反而加分） | 结论要硬，语气可以实在 |
| 调研报告 | 中 | 少量（引述受访者原话） | 事实陈述用书面，现场细节可用口语 |
| 公众号/宣传稿 | 低 | 较多 | 不在本技能范围 |
| 邮件/纪要 | 中 | 视对象 | 便条式纪要反而要口语 |

**关键判断**：读者是评委、审稿人、上级 → 保留正式度。读者是同事、群成员 → 可以松。

## 五、检测器

```bash
pf style 稿.docx                    # 直接查 docx
pf style draft.md --out 报告.md     # 查 markdown 并落报告
```

输出包含：

- **得分**（0–100，越高越像人写）：≥80 干净，65–79 轻度，45–64 明显，<45 模板感重
- **命中项**（按影响排序）：每项给命中次数、密度（每千字）、例句、改法
- **段落均匀度**：离散系数 <0.35 说明段落长度过于均匀，是机器生成信号
- **优先做的五件事**

判读原则：

- **得分不是目的**。95 分也可能有硬伤（数据、逻辑），60 分也可能只是列举多。
- **看命中项的性质**。C3（空泛归因）、A1（铺垫）、C1（拔高）是必改；B1（枚举）、D1（破折号）看情况。
- **不要为了分数把正常写法改掉**。四类产品的数据分类枚举是必要的。

## 六、改写提示词

给 AI 用的时候，别只说"去掉 AI 味"，要给约束：

```
把下面这段改写成申报书正文。

约束：
1. 保留全部数字、年份、样本量、人名，不得改动或新增任何数据。
2. 删掉铺垫句与总结句，第一句直接给结论。
3. 形容词一律换成可核对的事实；没有事实支撑的形容词删掉。
4. 超过 60 字的句子拆开。
5. 保留学术语体的正式度，不要口语化，不要加"说白了""其实"这类词。
6. 破折号压到零，改用冒号或断句。
7. 每段只讲一个主张。

输出只给改写后的正文，不要解释改了什么。

原文：
{粘贴}
```

改完必须人工核一遍数字——AI 改写最常见的事故是"顺手把 62.05 写成 62.1"，或者把"100+ 份"改成"约 100 份"，口径就漂了。
