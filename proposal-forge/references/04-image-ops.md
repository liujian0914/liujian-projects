# 04 · 图像运维

> 申报书里的图片问题集中在五个动作：压白底、换尺寸、换配色、改上面的字、换掉整张图。
> 每个动作都有一个"不做就会出事"的原因，逐条写清。

---

## 1. 透明 PNG 必须压白底

**现象**：一张看着很干净的透明 PNG，插进 Word/WPS 后变成一块黑。

**原因**：Word 与 WPS 都不对 PNG 的 alpha 通道做合成，透明像素直接按 RGB 值渲染，而透明区域的 RGB 通常是全 0（黑）。

```python
from PIL import Image
im = Image.open(src).convert("RGBA")
bg = Image.new("RGB", im.size, (255, 255, 255))
bg.paste(im, (0, 0), im)       # 第三参数是 alpha 蒙版
bg.save(dst)
```

```bash
pf whitebg ip.png     # 输出 ip_white.png
```

判断要不要压：`Image.open(p).mode` 为 `RGBA`/`LA`，或 `P` 且 `info` 里有 `transparency`，就需要。

实测案例：一张 IP 形象图 81% 的像素是透明的，直接插进去整块发黑，压白底后正常。

## 2. 两张竖图分别插会把题注挤到下一页

**现象**：IP 形象（2000×2000）和海报（1500×2000）分别插入，第二张的题注跑到下一页，页面上留一条孤零零的图。

**原因**：WPS 对**含嵌入图片的段落**不遵守 `keepNext` / `keepLines`，所以"图 + 题注"不保证同页。

**解法**：合成一张横排图，单图单题注。

```bash
pf hstack ip_white.png poster_white.png --out ip_poster.png --gap 24
```

合成后宽高比约 1.7，插 12.2cm 宽时高度可接受，题注也稳在同一页。

## 3. 换掉文档里的某张图

**不要用** `add_picture` —— 它只会新增一条关系，旧图仍留在包里，版式不变但文件名对不上。

直接改 zip 条目：

```bash
pf images 稿.docx --action list                                    # 先看清单
pf images 稿.docx --action replace --name image2.png --image 新图.png
```

两条硬约束：

- **尺寸必须与旧图一致**。新图 1600×900、旧图 2000×1123，插进去宽度不变但高度会被拉伸，整段版式跑位。改尺寸用 `Image.resize(..., LANCZOS)` 先对齐。
- **色彩模式必须一致**。旧图 RGBA 就存 RGBA。把 RGBA 存成 RGB，原本半透明的区域会变成实色。

## 4. 改图片上的文字（保留原风格）

场景：封面图上写错了一个词、架构图里某个模块要改名，但原图是 PNG，没有源文件。

五步法：

### 4.1 先看背景干不干净

取文字上下各几行采样。若背景是**纯色或平滑渐变**，用"逐列取文字上方与下方像素做垂直线性插值"就能干净还原，不需要 inpainting 库：

```python
for x in range(x0, x1):
    c_top, c_bot = arr[ty, x], arr[by, x]
    span = max(by - ty, 1)
    for y in range(y0, y1):
        t = (y - ty) / span
        fill[y, x] = c_top * (1 - t) + c_bot * t
```

背景是照片或复杂纹理时，这条走不通，改用"用邻近同色块整块覆盖 + 重绘"，或直接换图。

### 4.2 反解原字的三个量

- **墨迹高度**：暗像素（`mean < 150`）所在行的跨度。
- **文字颜色**：暗像素的**中位数**，不要用均值——抗锯齿边缘会拉偏。
- **水平中心**：墨迹列跨度的中点。

### 4.3 认字体

把候选字体各自渲染成同墨迹高度，比较**墨迹宽高比**与**墨迹占比**（`(arr < 128).mean()`），再拼一张对比图肉眼定夺。

可变字体（`*VF.ttf`）要用 `font.set_variation_by_axes([500])` 指定字重，否则拿到的是最细的那档。

### 4.4 重绘：同字高、同色、同中心

**不要改字号。** 新文字比原文长或短时，用**字间距**分摊差值：

```python
gap = (目标总宽 - 各字 advance 之和) / (字数 - 1)
```

改字号会让新字明显大一圈或小一圈，一眼看出来。

### 4.5 独立图层合成

新字画在独立的 `L` 模式图层上，与文字颜色做 `Image.composite`，边缘自然、不破坏背景。

```bash
pf retext 封面.png --out 新封面.png --box 720,180,1010,260 --text "新标题文字"
```

`--box` 是待替换文字的紧包围盒。返回结果里会给墨迹高度、反解出的颜色、算出的字间距，方便核对。

## 5. 图片资产的盘点

动手前先盘一遍，避免"插错了图"这种低级错误：

```bash
pf images 稿.docx --action list
```

输出每张图的尺寸、模式、是否被正文引用。实际排查过一个 61 张图的文档，结论是：

- `2848×1600` 那组是**信息图**（政策机遇、标准图谱、五层架构）；
- `1815×1005` 那组是**数据图表**（可重画，属于要统一配色的对象）；
- `6435×2172` 与 `5629×3776` 是**团队人员合影**（含他人肖像，不适合放申报书）；
- 唯一真正的**电脑端界面截图**是 `2000×1123` 那张。

尺寸分组是快速识别"这张图是什么"的可靠线索。

---

## 6. 统一插图宽度

参差不齐是"业余感"最直接的来源。8.2cm 到 13.4cm 混排，整篇看着就毛糙。

```bash
pf images 稿.docx --action width --cm 12.2
```

规则：只统一"整幅宽"的图（≥10cm），刻意做小的图**不要动**——办法截图、甘特图、近景照片本来就该小，统一反而更难看。

等比缩放高度，不裁切、不拉伸。

---

## 7. 图片格式选择

| 用途 | 格式 | 理由 |
|---|---|---|
| 数据图、示意图 | PNG | 文字边缘锐利，无压缩噪点 |
| 照片、实拍 | JPEG（质量 88+） | 体积小，噪点不明显 |
| 需要透明 | PNG | Word 里记得压白底 |
| 打印交付 | 300dpi 起点 | 低于 150dpi 打印发虚 |

申报书 docx 体积失控九成是图太大。一张 6000×4000 的照片缩到 2000px 宽足够 12cm 打印，体积能降一个数量级。

## 8. 肖像与隐私

插入合影或他人照片前确认授权。**证件图像（身份证、银行卡、驾驶证）绝不上传到公开网络，也不放进任何对外材料。** 团队照片里若含不愿露脸的成员，宁可不放。
