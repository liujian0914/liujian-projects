# 生图提示词模板

> 申报书里的"生图"只做三件事：**IP 形象、海报、界面概念图**。
> 含精确文字与数字的架构图、数据图**不要用生图**——文字会糊、数字会错。

---

## 一、四段式结构

任何一条提示词都按这个顺序写：

```
① 主体：画什么（具体的物，不要抽象概念）
② 风格：什么画风（3D 渲染 / 扁平插画 / 手绘 / 摄影）
③ 用途与构图：给谁看、什么比例、留白在哪
④ 禁止项：不要什么（比"要什么"更管用）
```

---

## 二、IP 形象（吉祥物）

申报书里的 IP 是"产品助手"的人格化，要求是**亲切、可信、不幼稚**。

### 模板

```
主体：一只圆润的卡通刺猬形象，怀里抱着一本打开的浅蓝色手册，
      背上点缀红色果实与绿叶，胸前挂一枚盾牌形状的徽章。
风格：3D 卡通渲染，柔和体积光，磨砂质感，低饱和的米白+浅绿+浅蓝配色，
      类似现代品牌吉祥物的商业插画风格。
用途与构图：思政/助农类项目的产品助手形象，正方形 1:1，纯白背景，
      角色居中，四周留 12% 留白，正面朝向观众，表情友善。
禁止项：不要文字、不要阴影投在地面、不要复杂背景、不要写实毛发、
      不要成人化比例、不要过饱和荧光色。
```

### 多姿态一致性

同一个 IP 要出多个姿态（站立、讲解、指引）时：

1. 固定**同一段描述词**，只改"姿态"那一句；
2. 固定随机种子（如模型支持）；
3. 生成后统一做白底处理，再并排看是否"是同一个"。

不一致就重生成，不要靠修图硬拼——拼出来的比例会飘。

### 生成后处理

```bash
pf whitebg ip.png          # 透明背景压白底，否则插 Word 变黑块
```

## 三、海报

申报书里的海报用于"产品介绍"章节，要求**信息层级清楚**。

### 模板

```
主体：一款助农AI助手的宣传海报，画面左侧为竖排大标题位置（留空），
      右侧为卡通刺猬助手形象，下方为三个并排的功能卡片（各留空待填文字）。
风格：清透的浅蓝到米白渐变，柔和投影，信息图风格，简洁现代，
      参考科技产品发布会主视觉。
用途与构图：A4 竖版（1:1.41），上方 1/3 留白放标题，中部为主体视觉，
      下方 1/4 为功能模块区。整体留出可插入中文文字的空位。
禁止项：不要生成任何文字、不要生成数字、不要复杂纹理背景、
      不要人物照片、不要超过四种主色。
```

**关键**：明确要求"文字位置留空"，生成后自己用修图工具或 HTML 排版加中文字。让模型直接生成中文，出错率极高。

## 四、界面概念图（UI Mockup）

真实截图最优。没有截图时，用生图做概念图，并在图注里标注"界面示意图"。

### 模板

```
主体：一个平板电脑上的助农数据看板界面，顶部为深青色导航栏（六个菜单项位置留空），
      左侧为农户操作路径的五步流程（图标+文字位留空），
      中部为数据卡片区域（三块），右侧为一个卡通助手侧栏。
风格：现代 B 端 SaaS 界面，卡片式布局，柔和圆角，浅灰背景，
      深青色主色 + 米白辅色，扁平化图标。
用途与构图：横版 16:9，正面平视，屏幕内容占画面 90%，
      不加设备外框阴影，纯白背景。
禁止项：不要生成可读文字、不要生成真实数据数字、不要人物照片、
      不要玻璃拟态反光、不要超过三列布局。
```

**注意**：UI 概念图里的文字一律留空，生成后用 Figma/PPT 补；否则会出现"看起来像乱码"的假字。

## 五、场景与氛围图

用于"应用场景""社会价值"章节。

```
主体：一位中年农户站在蔬菜大棚内，手持手机查看屏幕上的检测报告，
      背景是大棚结构与绿色作物，自然光从右侧射入。
风格：纪实摄影，50mm 焦段，浅景深，自然色调，不做过度修图。
用途与构图：横版 3:2，人物在画面右侧 1/3，左侧留白用于排版文字。
禁止项：不要人脸特写、不要看镜头、不要商业摆拍感、不要文字水印。
```

> 涉及真实人物肖像的场景图，**只能作为示意图使用**，图注必须写明"示意图"，不能暗示是项目实拍。

## 六、不可用的场景

| 想做的图 | 为什么不行 | 改用什么 |
|---|---|---|
| 五层技术架构图 | 文字必糊，层名对不上 | `pf chart` framework 或 draw.io |
| 数据图表 | 数字是假的 | matplotlib |
| 流程图/甘特图 | 时间节点会错 | `pf chart` |
| 带中文标题的海报 | 中文字形错乱 | 生图留空 + 后期加字 |
| 项目团队合影 | 人脸是虚构的 | 用真实照片（需授权） |

---

## 七、通用调参

| 参数 | 建议 | 说明 |
|---|---|---|
| 尺寸 | 2000×2000 或 2400×1350 | 够 12cm 宽 300dpi 打印，再大只是让 docx 变肥 |
| 每批数量 | 4 张 | 一次出太多挑不过来 |
| 随机种子 | 固定 | 同一 IP 多姿态必须固定 |
| 负向提示 | 必填 | "不要文字"是最有用的负向词 |

---

## 八、入库前的三步

1. **看**：原尺寸打开看一遍，尤其看手指、文字区、边缘过渡有没有崩。
2. **压白底**：`pf whitebg`。
3. **统一色调**：与本文其他图不一致时，`pf recolor` 或调色到同一家族。

生成图不加处理直接插，是"业余感"最快的来源。
