# 大学生创新训练项目申请书 · 骨架

> 以高校通用版《大学生创新训练项目申请书》为基准，各校略有差异，**以当年官方模板为准**。
> 典型体量：正文 1.2–1.6 万字 / 20–30 页 / 20–30 张图。填写说明通常要求"简明扼要"，不要硬凑。

---

## 结构总览

```
封面
填写说明
一、基本情况（表格，固定结构）
二、立项依据（正文主体，1×1 表格内）
三、经费预算（表格，固定结构）
四、指导教师意见
五、学院意见
六、学校意见
```

**注意**：二、立项依据常常整体装在一个 1×1 表格单元格里。编辑时必须用穿透遍历，`doc.paragraphs` 会返回空。

---

## 一、基本情况表

固定字段，不要加行、不要合并单元格：

| 项目 | 内容 |
|---|---|
| 项目名称 | 全称，不要简称 |
| 项目类别 | 创新训练 / 创业训练 / 创业实践 |
| 所属学科 | 一级门类 + 二级类 + 专业代码 |
| 项目负责人 | 姓名 / 学号 / 专业 / 年级 / 电话 / 邮箱 |
| 团队成员 | 3–5 人，姓名 + 学号 + 分工 |
| 指导教师 | 姓名 / 职称 / 单位 / 电话 |
| 申请金额 | 元 |
| 起止时间 | 年月 — 年月（一般 12–18 个月） |

**提前确认的字段**（本人常缺）：民族、出生年月、指导教师及电话、项目编号。

---

## 二、立项依据

### 1 研究目的与意义（600–900 字）

- 1.1 研究背景：给**可核对的时点与文件**（政策名 + 发布年 + 关键数字），不要写"随着…的发展"
- 1.2 研究目的：三条以内，每条一个动词 + 一个可验收的产出
- 1.3 研究意义：理论（补什么缺口）+ 实践（解决谁的什么问题）

### 2 国内外研究现状和发展动态（1,500–2,500 字）

- 2.1 国外：按"制度—效果—争议"三条线梳理，指出分歧
- 2.2 国内：按"政策—地方实践—实证研究"梳理
- 2.3 评述与空白：明确说"已有研究解决了 X，未解决 Y，本项目做 Y"
- 每条判断都要有文献支撑，正文标注 `[n]`，与文末列表一一对应

**这一节的常见失败**：文献堆砌成"某某认为…某某指出…"，没有对话。要有"关于这点有两派，本文站在哪边、为什么"。

### 3 研究内容（1,500–2,500 字）

分 3–5 块，每块：

```
（1）标题：一句能读懂的任务名
    做什么 → 怎么做的关键步骤 → 产出什么（可验收）
```

配一张**研究框架图**（`framework` 图型），把几块内容的关系画出来。

### 4 研究方法与技术路线（1,200–2,000 字）

- 4.1 研究方法：文献研究 / 实地调研 / 问卷调查 / 访谈 / 实验 / 案例比较，每种说清"用来解决哪个问题"
- 4.2 抽样方案：抽样框、样本量依据、信效度方案、对照组设置
- 4.3 技术路线：四阶段图（准备—调研—开发—验证），每阶段有交付物

**方法细节是区分"真做过"和"编的"的地方。** 写"发放问卷 120 份，回收 108 份，剔除无效 5 份，有效 103 份，有效率 85.8%"比写"进行了问卷调查"有力得多。

### 5 创新点（600–900 字）

2–3 条，每条一个"与现有做法的差异"：

```
（1）视角差异：现有研究从 A 切入，本项目从 B 切入，因为……
（2）方法差异：用 X 方法解决了 Y 方法无法处理的 Z
（3）应用差异：从"提出建议"推进到"可运行的工具"
```

不要写"首次""填补空白"这类无法证伪的话。

### 6 进度安排（400–600 字 + 甘特图）

按"第 N 月"相对记，不含年份（改了起止时间不用全文改）：

| 阶段 | 时间 | 任务 | 交付物 |
|---|---|---|---|
| 准备 | 第 1–2 月 | 文献、抽样框、工具开发 | 文献综述、量表 |
| 调研 | 第 3–6 月 | 实地走访、问卷 | 数据库（≥N 份） |
| 开发 | 第 5–11 月 | 平台/工具原型 | 可演示原型 |
| 验证 | 第 9–13 月 | 内测试点 | 前后测报告 |
| 总结 | 第 13–14 月 | 论文、结题报告 | 2 万字报告 + 投稿 |

### 7 预期成果（300–500 字）

可验收的：

- 研究报告 1 份（约 N 万字）
- 学术论文 1–2 篇（拟投期刊名 + 投稿时间）
- 软件/平台 1 个（功能清单 + 演示方式）
- 数据库 1 套（样本量 + 字段说明）
- 竞赛/专利/软著（如适用）

### 8 条件保障（400–600 字）

- 团队：成员分工与既往经历（真实，不夸大）
- 指导教师：研究方向与相关成果
- 依托单位：实验室、数据、经费
- 已有基础：前期调研、原型、合作单位

### 9 风险与应对（300–500 字）

四类风险各一条，写"如果…则…"：

- 数据风险：样本不足 → 扩大抽样框 / 补充访谈
- 技术风险：原型延期 → 缩范围保核心两模块
- 协作风险：成员流动 → 文档化交接
- 外推风险：单区域结论 → 明确边界，不外推

---

## 三、经费预算

固定表格，科目通常是：图书资料费、数据采集费、差旅费、会议费、设备费、材料费、测试化验加工费、出版/文献/信息传播/知识产权事务费、劳务费、专家咨询费、其他。

要点：

- 合计必须等于申请金额
- 每个科目给一句"用途 + 测算依据"（如"差旅费 3,000 元：4 个产区 × 2 人 × 375 元/次"）
- 不要出现"其他"占大头

---

## 四、五、六 意见栏

留空，交给指导教师与学院填写。不要代填，也不要删。
