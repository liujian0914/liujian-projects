# 中国国际大学生创新大赛（国创赛）申报书 · 骨架

> 以高教主赛道/青年红色筑梦之旅赛道的通用商业计划书结构为基准。**以当年官方通知与模板为准。**
> 典型体量：1.5–3 万字 / 25–40 页 / 25–35 张图 / 附 PPT。

国创赛申报书与"科研型"申报书的根本差别：**它是投资与商业逻辑，不是学术逻辑。** 评委关心"这事儿能不能成、能有多大、你凭什么做成"。

---

## 结构总览

```
封面
项目摘要（1 页，最重要）
一、项目概述
二、行业与市场分析
三、产品与技术服务
四、商业模式
五、竞争分析
六、营销与运营
七、团队
八、财务预测与融资
九、风险与对策
十、社会价值 / 育人成效（红旅赛道必写）
附录（证明、专利、合同、调研原始材料）
```

---

## 项目摘要（1 页，300–500 字）

**这一页决定评委要不要往下读。** 五句话结构：

1. 我们做什么（一句话说清产品形态）
2. 解决谁的什么问题（痛点，带数字）
3. 怎么解决（技术/模式的核心差异，一句话）
4. 已经做到什么（最硬的三个数据：用户数、收入、合作方、获奖）
5. 要什么、给什么（融资额/资源 + 预期回报）

不写背景、不写愿景、不写"我们相信"。

---

## 一、项目概述（800–1,200 字）

- 1.1 项目背景：痛点必须**可量化**（"四类产品标准执行率仅 40.2%，认知 75.3%，落差 35 分"）
- 1.2 解决方案：一张架构图 + 一段说清运行机制
- 1.3 发展现状：现在到哪一步了（原型/试点/营收/合作方）
- 1.4 项目定位：一句话，"我们是谁的什么"

---

## 二、行业与市场分析（1,500–2,500 字）

- 2.1 行业规模与趋势：**必须有权威来源与年份**（国家统计局、行业协会年报、券商研报）
- 2.2 政策环境：列 3–5 份直接相关的文件（名称 + 发布机关 + 年份 + 关键条款）
- 2.3 目标市场：TAM / SAM / SOM 三层，每层给算法
- 2.4 用户画像：B 端写组织规模与决策链，C 端写人群特征与付费意愿
- 2.5 市场时机：为什么是现在（技术成熟度、政策窗口、成本拐点）

**常见失败**：市场规模写"万亿级蓝海"却不给算法。评委一眼看出是抄的。

---

## 三、产品与技术服务（2,000–3,500 字）

- 3.1 产品形态：移动端 / PC 端 / 硬件，配界面图（真实截图优先，没有就写实的概念图并标注"示意图"）
- 3.2 核心功能：3–6 个模块，每个模块"输入—处理—输出"
- 3.3 技术架构：分五层画（应用层 / 能力层 / 数据层 / 基础设施 / 安全），层间箭头不要压字
- 3.4 关键技术：只写真正用到的。用了开源底座就写清楚，不要含糊成"自研"
- 3.5 知识产权：专利/软著/商标，列申请号或授权号（没有就写"拟申请"，别编）
- 3.6 产品路线图：MVP → V1 → V2，每阶段功能与时间

**诚信边界**：团队参与开发的写"参与研发"，不要写成"独立开发"；用第三方 API 的写明；用开源组件的注明许可证。

---

## 四、商业模式（1,200–2,000 字）

- 4.1 价值主张：一句话
- 4.2 客户与付费方：谁用、谁付钱（这两者常常不是同一个）
- 4.3 收入模式：订阅 / 按次 / 分成 / 服务费 / 政府采购，每种给单价与测算
- 4.4 成本结构：固定成本（研发、服务器）+ 变动成本（获客、交付）
- 4.5 单位经济模型：LTV / CAC / 回本周期，给算式
- 4.6 规模化路径：单点验证 → 区域复制 → 跨品类

---

## 五、竞争分析（800–1,200 字）

- 5.1 竞争格局：三类竞争者（直接、间接、替代方案）
- 5.2 对比矩阵：5–8 个维度 × 3–5 个对手，用热力图或对勾表
- 5.3 壁垒：技术 / 数据 / 渠道 / 政策资质 / 网络效应，选 1–2 个真正成立的
- 5.4 差异化：一句话说清"为什么客户选我们"

**不要写"我们没有竞争对手"**，这是最容易被扣分的表述。

---

## 六、营销与运营（800–1,200 字）

- 6.1 获客渠道：每个渠道给成本与转化率估算
- 6.2 种子用户获取：前 100 个用户怎么来的（真实路径最有说服力）
- 6.3 运营体系：服务流程、响应时效、复购设计
- 6.4 品牌与背书：竞赛奖项、媒体报道、合作单位（真实）

---

## 七、团队（800–1,200 字）

- 7.1 核心成员：姓名 + 角色 + 与角色匹配的经历（不要写与项目无关的荣誉堆砌）
- 7.2 指导教师 / 顾问：研究方向与能提供的资源
- 7.3 组织架构：谁负责技术、市场、财务
- 7.4 人才规划：未来 12 个月补哪些岗

**红旅赛道**：要写清与乡村振兴/红色基因的实质关联，不能只在标题里贴标签。

---

## 八、财务预测与融资（1,000–1,800 字）

- 8.1 三年预测：收入、成本、毛利、净利，给假设前提（用户数 × 客单价）
- 8.2 现金流：什么时候打平
- 8.3 融资计划：金额、用途分配、估值逻辑、出让比例
- 8.4 敏感性分析：关键变量 ±20% 时的影响

**口径必须前后一致。** 真实事故：第三章的收入表写首年 17 万，第五章财务预测写 8 万，被一眼看穿。

---

## 九、风险与对策（500–800 字）

政策风险 / 技术风险 / 市场风险 / 团队风险 / 财务风险，每条"如果…则…"，要有可执行的应对，不要写"加强管理"。

---

## 十、社会价值 / 育人成效（红旅赛道，800–1,200 字）

- 带动多少农户/合作社增收（给算法）
- 创造了多少就业/实习岗位
- 与思政教育、专业实践的结合点
- 可复制的推广模式

---

## 附录

调研问卷、原始数据样例、专利受理通知书、合作协议、用户证言、媒体报道截图。**证言与合同要打码个人信息。**

---

## 自查清单

- [ ] 摘要能在 30 秒内让人明白做什么、做到什么程度
- [ ] 市场规模有算法，不是"万亿蓝海"
- [ ] 有真实界面图或明确标注的示意图
- [ ] 收入口径全文一致（第三章 vs 第八章）
- [ ] 竞争分析有具体对手，不是"没有竞争对手"
- [ ] 技术描述与实际开发程度匹配，不夸大
- [ ] 团队经历与角色匹配，不堆无关荣誉
- [ ] 图表风格统一，架构图配色有家族
- [ ] 附录证明材料齐全且脱敏
